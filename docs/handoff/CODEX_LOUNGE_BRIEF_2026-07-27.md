## 0. 배경·목적

- 코어 학습 미션(MPJ5+DCT1)은 연구 구인이라 크게 못 바꾼다 → **연구 목적·제약이 전혀 없는** 재미 코너를 별도로 신설해 주간 수업 앱의 engagement를 올린다.
- 아이디어 출처: NotebookLM 소스 리서치(게이미피케이션·중국어 재미 콘텐츠·교실 활동) 10후보 → 코드베이스 기준 필터링 → 3개 확정.
- 사용자 피드백 3건 반영: ①각 코너에 가벼운 화용·통역 학습 요소 추가(차별화) ②완료 화면 내장이 아니라 **별도 코너 허브로 분리**(라우트 신설 1~2개) ③**수준별(입문/중급/고급) 맞춤**.

## 2. 코너 B — 🎬 생생극장 (`/learner/lounge/theater`)

주차·수준별 유튜브 쇼츠 클립 + 2단 구성:
1. **"이 장면의 한 끗" 1문항** — 수준별 깊이 차등: 입문=이 표현이 쓰인 상황, 중급=뉘앙스 차이, 고급=이 말투가 드러내는 관계. 채점·기록 없음, 즉시 정답+한 줄 해설.
2. **"통역 도전"(선택)** — 클립을 다시 재생하며 한국어를 얹어 말해보기. **녹음·STT·채점 없음**(통역랩과 별개인 장난감 버전임을 문구로 명시). 끝나면 모범 통역 1줄 공개 + "해냈다/다음에" 자기 체크 한 탭.

- 데이터: `fun_clips` (week_no, level nullable, video_url, title, hook_text, quiz jsonb, model_interpretation). 관리자 입력은 `AdminYoutubeSources` 확장.
- 상태: 수준별 클립 없으면 공통 fallback, 영상 로드 실패 시 외부 링크만.
- 불변: 미션 화면 전체, 통역랩.

```text
┌ 🎬 생생극장 · 6주차 (중급) ────────┐
│ [쇼츠 ▶] "老板又画饼了…"           │
│ ① 한 끗: 画饼, 여기선 무슨 뉘앙스? │
│    ○ 칭찬  ● 헛약속 비꼼  ○ 요리   │
│ ② 🎙 통역 도전 — 다시 재생하며     │
│    한국어로 얹어 말해보세요 (기록X) │
│    → 모범: "사장이 또 희망고문하네"│
└────────────────────────────────────┘
```

## 3. 코너 C — 😂 밈 배틀 (`/learner/lounge/meme`)

주차별 **공통 밈 1개**(전원 같은 밈 — 투표 풀 유지) + **수준별 조건 카드**로 한국어 캡션(번역) 제출 → 익명 투표 → 상위 3 공개.
- 조건 카드 = 화용 요소: "누구에게 보내는 버전인가" (입문="찐친에게", 중급="회사 단톡방용", 고급="자막 번역가처럼 — 문화 주석 없이 웃겨야 함"). 투표 기준 = 조건 충족 + 재미.
- 3단계 상태: 제출기간 → 투표기간(익명 목록, 1인 1표) → 결과(상위 3만, **전체 순위·리더보드 금지** — 불안 방지). 실명 기본 비공개(선택 공개).
- 데이터: `meme_battles`(week_no, image_url/text_prompt, condition_cards jsonb[3수준], status), `meme_entries`(battle_id, user_id, caption_ko — 1인 1캡션), `meme_votes`(entry_id, voter_id — 1인 1표). RLS 필수.
- 밈 이미지는 저작권 때문에 교수 큐레이션(자작/라이선스) 또는 텍스트 유행어 중심.

```text
┌ 😂 밈 배틀 #6 · 투표중 D-2 ────────┐
│ [밈: 脆皮打工人 그림]              │
│ 🎯 내 조건(중급): 회사 단톡방에    │
│    올려도 안 잘리는 번역으로!      │
│ ○ "유리몸 직장인"   …익명 목록     │
│           [이 캡션에 1표]          │
└────────────────────────────────────┘
```

## 4. 코너 D — 💬 해독실 (`/learner/lounge/decoder`)

WeChat풍 채팅 버블에서 숫자코드·신조어 해독. 수준별 팩(5~7문항): 입문=숫자코드(520·88·666), 중급=신조어·직장 유행어(打工人·内卷), 고급=반어·밈의 유래·번역불가어(+"한국어로 옮기면?" 보너스 1문항).
1. 뜻 해독(선택형) → 즉시 정답 + 해설 한 줄
2. **눈치 체크** — "이거 누구에게 보내도 될까?" 상대 아이콘(찐친/선배/교수님)별 O/X 한 탭
- **DB 기록 없음** — localStorage 완료 표시만. 재도전 무제한, 팩 완료 스탬프.
- 데이터: `decoder_packs`(week_no, level, title, items jsonb). 콘텐츠 테이블만, 학습자 기록 테이블 없음.

```text
┌ 💬 해독실 · 고급 팩 ───────────────┐
│ 상대: 你可真是个大聪明 🙂          │
│ ① 진심일까?  ○ 칭찬  ● 반어(비꼼)  │
│ ✓ 大聪明 = 반어. 🙂도 위험 신호    │
│ ② 눈치 체크: 누구에게 가능?        │
│    찐친 [O]  선배 [X]  교수님 [X]  │
│ ③ 보너스: 한국어로 옮기면?         │
└──────────────── 4 / 6 ────────────┘
```

## 5. 제약·금지 (전 코너 공통)

1. **연구 완전 분리** — 신규 테이블은 연구 테이블(scenarios·learner_mission_logs 등)과 무관. 라운지 활동은 연구 데이터가 아니며, 화면에 "쉬어가기 콘텐츠 · 기록되지 않아요" 명시.
2. **MPJ 형식 겹침 금지** — 코어는 "시나리오+선택지 적절성 판정" 형식이므로, 코너의 학습 요소는 O/X 한 탭·조건 카드·따라 말하기 등 **다른 형식**으로만. 미니 MPJ처럼 보이면 안 됨.
3. **리더보드·점수·감점 금지**(기각 목록 계승). 밈 배틀 결과는 상위 3만.
4. 생성계약(`0-*`)·학습 미션·수준층·15주 편성 **무변경**. 생성계약은 이 건으로 개정 없음(라운지 콘텐츠는 별도 파이프라인).
5. 매주 공급 부담 최소화: 수준별 fallback 허용, 콘텐츠 생성은 관리자 파이프라인(edge) 재사용 가능하되 **신규 edge action 추가·배포는 사용자 승인 필요**.

- **Codex 규칙**: 브랜치 `codex-0727`(파생 시 `codex-0727-lounge`), **push·deploy·`supabase db push` 전부 금지** — migration은 로컬 파일 작성까지만. typecheck = `npm run typecheck`만 신뢰. 라운지 착수는 스모크·동결·배치 완료 후에만.
