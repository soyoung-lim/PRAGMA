# PRAGMA 전면 UI QA

- 기준일: 2026-07-28 (KST)
- 브랜치: `codex/lounge-release-2026-07-28`
- 범위: 비-MPJ 프론트엔드 라우트·내비게이션·반응형·콘솔 오류
- 제외: MPJ 설계, 미니 모듈, 생성 프롬프트, DB, Edge Function, 배포, 배치

## 점검 범위

- 학습자·진입 화면 18개 라우트
- 관리자 화면 21개 라우트
- 공개·인증·리디렉션 10개 라우트
- 화면에서 노출되는 내부 링크 대상
- 빈 화면, 의도하지 않은 404, 이름 없는 버튼, 빈 링크
- 학습자 주요 화면 390px 모바일 폭
- 관리자 390px 모바일 폭

## 결과

### 통과

- 등록된 점검 라우트에서 의도하지 않은 404 없음
- 빈 React root 없음
- 노출된 내부 링크의 미등록 목적지 없음
- 빈 `href`, `#`, JavaScript 링크 없음
- 접근 가능한 이름이 없는 가시 버튼 없음
- 학습자 화면의 수평 넘침 없음
- 학습자 하단 `홈 / 수업 / 라운지 / 기록` 내비게이션 정상
- 학습자 점검 구간의 콘솔 오류 없음
- 학습 노트는 2주차 샘플·잠금 상태·복귀 링크까지 정상
- 실제 강좌가 없을 때 빈 상태가 로딩 상태 대신 정상 표시됨

### 수정

관리자 사이드바는 `md` 미만에서 숨겨졌지만 대체 내비게이션이 없어 모바일에서 다른 관리자 화면으로 이동할 수 없었다.

- `AdminShell`에 모바일 전용 관리자 메뉴 `select` 추가
- 기존 사이드바와 같은 그룹·순서 사용
- 준비 중 화면은 옵션에도 `준비 중` 표시
- 선택 시 해당 관리자 라우트로 정상 이동 확인
- 데스크톱 사이드바 동작은 변경하지 않음

## 인증·운영 한계

- 분리 worktree의 로컬 점검은 개발용 관리자 진입 상태에서 수행했다.
- 실제 관리자 Supabase 세션이 아니므로 일부 DB 조회는 `permission denied`를 반환했다.
- 이는 화면 크래시가 아니라 인증되지 않은 DB 읽기의 예상 결과이며, 실제 관리자 데이터 왕복 검증으로 간주하지 않는다.
- Prompt Harness의 배포 해시와 원격 migration 상태는 이번 UI QA에서 변경하거나 재판정하지 않았다.
