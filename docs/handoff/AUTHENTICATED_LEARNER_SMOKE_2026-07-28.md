- 브라우저 콘솔 `error` 없음

## 발견: 학습자 상태의 두 정본이 충돌함

`/learner/home`과 `/learner/course`는 다음 샘플 진행 상태를 실제 현재 상태처럼 표시한다.

- `이번 주 과제 · 요청 화행`
- `2주차 · 요청`
- 진행률 `1 / 3`
- `오늘의 학습 시작하기`
- 직접 연습 `0 / 4`

그러나 DB 기반 `/learner/course-live`의 실제 상태는 다음과 같다.

- 게시된 15주 커리큘럼 1개
- 검토 완료·배정 과제 0개
- 각 주차에 `아직 배정된 과제가 없습니다`

따라서 학습자는 홈과 기본 과정 화면에서 과제가 있는 것으로 이해하지만, `편성된 실제 강좌`에 들어가면 실행할 과제가 없다. 이는 인증·RLS 오류가 아니라 **legacy/sample 학습 경로와 DB 기반 실제 강좌가 동시에 현재 상태처럼 노출되는 정보 구조 문제**다.

## 판정

- 인증 세션의 학습자 읽기 경로: **통과**
- 실제 learner 역할 RLS 검증: **미완료**
  - 이번 세션은 관리자 역할이므로 일반 learner 계정과 같은 권한 검증으로 간주하지 않음
- 학습자 현재 상태의 일관성: **실패**
- 운영 배포: **보류**

## 권고

MPJ 구조를 건드리지 않고 먼저 해결할 수 있다.

1. `/learner/home`의 샘플 과제·진행률을 실제 편성 데이터 또는 명시적인 빈 상태로 교체
2. `/learner/course`에서 목업 15주 경로와 DB 기반 `course-live` 중 어느 쪽이 정본인지 하나로 통합
3. 실제 learner 계정으로 공개 커리큘럼과 노트 RLS를 한 번 더 확인

이번 점검은 MPJ, 생성 계약, 프롬프트, DB schema, Edge Function, core hash를 변경하지 않았다.
