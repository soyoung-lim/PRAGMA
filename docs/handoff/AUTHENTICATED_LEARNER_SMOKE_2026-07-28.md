## 발견: 학습자 상태의 두 정본이 충돌함

`/learner/home`과 `/learner/course`는 다음 샘플 진행 상태를 실제 현재 상태처럼 표시한다.

- `이번 주 과제 · 요청 화행`
- `2주차 · 요청`
- 진행률 `1 / 3`
- `오늘의 학습 시작하기`
- 직접 연습 `0 / 4`

그러나 DB 기반 `/learner/course-live`의 실제 상태는 다음과 같다.

- 게시된 15주 커리큘럼 1개
- 검토 완료·배정 과제 0개
- 각 주차에 `아직 배정된 과제가 없습니다`

따라서 학습자는 홈과 기본 과정 화면에서 과제가 있는 것으로 이해하지만, `편성된 실제 강좌`에 들어가면 실행할 과제가 없다. 이는 인증·RLS 오류가 아니라 **legacy/sample 학습 경로와 DB 기반 실제 강좌가 동시에 현재 상태처럼 노출되는 정보 구조 문제**다.

## 후속 수정

같은 날 비-MPJ 프론트 범위에서 정본 충돌을 해소했다.

- 홈과 수업이 같은 게시 강좌 조회를 공유함
- `/learner/home`에서 샘플 과제·진행률·프로파일을 제거함
- 홈은 실제 `15주 과정 · 검토 완료 과제 0개 · 과제 배정 전` 상태를 표시함
- `/learner/course`를 DB 기반 강좌의 단일 정본으로 변경함
- `/learner/course-live`와 구 2주차 일반 주소는 `/learner/course`로 복귀함
- 고정 2주차 과정·도입·전략 지도·샘플 노트는 개발 전용 `/learner/demo/*`로 격리함
- 일반 주차 노트는 게시 강좌 데이터가 없을 때 샘플로 자동 대체되지 않음
