## 오늘 반영한 주요 변경

### 전체 진행과 레이아웃

- 기존 가로 헤더 대신 왼쪽 고정 세로 진행바를 사용한다.
- 진행바의 과거 단계는 다시 볼 수 있고 현재 단계로 복귀할 수 있다.
- `모듈 1`, `모듈 2`, `<-현재 단계` 표시는 삭제했다.
- 진행바는 `현재 / 10 학습 단계`로 표시한다.
- 7·10번 `피드백·다듬기`는 미색 배경과 Sparkles 아이콘으로 일반 문제와 구분하며, 완료 후에는 체크를 유지한다.

### 시작 화면

- 3개 정보 카드(`10단계`, `약 30분`, `중급·HSK5`)를 제거하고 에디토리얼형으로 개편했다.
- 현재 카피:
  - `2주차 · 요청`
  - `상황에 맞게 부탁하기`
  - `누구에게, 어떤 상황에서 부탁하느냐에 따라 표현도 달라집니다.`
  - `판단하기 → 직접 번역하기 → 피드백으로 다듬기 → 바뀐 상황에 다시 적용하기`
  - 배지: `중급 · HSK 5 수준 권장`
- CTA는 `미션 시작하기` 하나만 둔다.

### DCT 피드백과 summary

- 각 DCT 직후 별도 피드백·다듬기 화면을 배치했다.
- 피드백은 AI 분석 중 상태 뒤에 학생이 실제 작성한 중국어, 실제 문제 구간, 틀린 이유, 수정 방향, 기억할 한 가지를 보여 준다.
- 긴 원문·메타데이터·대안 목록·이론 설명은 제거했다.
- 최종 summary는 성격이 다른 번역 1·2를 좌우 대칭 비교하지 않는다. 각 답안을 세로 독립 기록으로 제시한다.
- summary의 메타 분석은 두 답안에서 실제 확인된 세 기준의 패턴만 집계한다.
