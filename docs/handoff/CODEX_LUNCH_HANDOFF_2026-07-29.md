## 2. 확정된 mission_v4 학습 구조

```text
1단계 감각 익히기
  Scale4 독립 판단
  → Judge3 + FixChoice 4
  → Reason 3, Judge 반복·확신도 없음
  → MultiJudge 4

2단계 직접 표현하기
  번역 또는 통역 한 가지 주 수행
  → 피드백

3단계 돌아보고 다듬기
  모두 통과: 이 표현으로 완료 / 선택적 다른 표현
  조절 필요: 한 번 다듬어보기
  → 완료
```

- Scale4는 `매우 적절 / 다소 적절 / 다소 부적절 / 매우 부적절`이며 적절·부적절 방향만 정오 판단한다.
- Judge와 Correction은 한 문항이지만 UI에서 판단 제출 후 교정안을 순차 공개한다.
- Reason은 부적절함을 전제하고 가장 큰 원인 하나만 고른다.
- Confidence는 삭제했다.
- 번역+통역 companion 학습은 교육적으로 유력하지만 저장 계약과 과목 설정이 필요한 후속 범위라 아직 구현하지 않는다.

## 3. 7월 29일 학습자 UI 확정사항

- P·D·R 원시 라벨이나 `역할/관계/부담` 표를 학생에게 노출하지 않는다.
- 상황은 자연스러운 1인칭 장면과 구체적 부담으로 쓰고 문장별로 줄을 나눈다.
- `상대` 칩에는 상대 역할·관계만 표시한다. 화자 역할이나 `A → B`를 함께 넣지 않는다.
- 상단에는 `요청 · 상대가 거절할 여지를 남기며 부탁하기`처럼 화행과 학습자 언어 초점을 고정한다.
- 상황 카드와 메신저/오디오 수행 도구를 분리한다.
- 메신저 상태는 `메시지 작성 중`, 번역 장면 신호는 `지금, 직접 번역할 장면`, 단계명은 `번역하기`다.
- MPJ 선지 카드 상단에 네이비 3px 시작선을 두어 문제와 응답을 구분한다.
- 번역 힌트는 입력창 위 우측의 작은 `막히면 힌트 보기` pill이다. 기본 접힘이며 부연 문구는 없다.
- 통역은 검은 듣기·녹음 스튜디오와 밝은 전사 확인 카드를 분리했다. ±0.5초 버튼과 중복 설명은 삭제했다.
- 피드백 세 기준은 `의미 전달 / 문법 정확성 / 상황 적절성`이다.
- 주 피드백 제목에서 `AI`를 반복하지 않고 하단 참고 고지에만 투명하게 남긴다.
- MPJ 네 문항 뒤 기존 handoff에서 실제 응답을 네 개의 한 줄 SUMMARY로 정리한 다음 직접 산출로 이동한다.
- 다듬기는 한 줄 수정 행동, 완료 화면은 수정 전후·바뀐 부분·실제 판정에 맞춘 한 줄 조언·다음 행동만 남긴다. 라운지 진입과 반복 교육 카드는 제거한다.
