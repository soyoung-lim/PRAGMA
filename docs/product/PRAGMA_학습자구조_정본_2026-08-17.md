# PRAGMA 학습자 미션 구조 정본 — 2026-08-17

## 최종 흐름

```text
메타화용 판단 4문항
→ 새 사건·같은 기준 P·D·R의 독립 DCT
→ 의미 / 문법·표현 / 목표 화용 특성 피드백
→ 실질 수정 또는 근거 있는 유지
→ 경량 재확인 1회
→ 필요 시 추가 수정 1회 후 종료
```

## 학습자 경험

| 단계 | 화면에서 하는 일 | 화면이 하지 않는 일 |
|---|---|---|
| Scale4 | 첫인상 적절성을 4점으로 판단하고 제출 뒤 참고 판정을 비교 | 다소/매우 차이를 오답 처리하지 않음 |
| FixChoice | 제시안의 대역 판단을 먼저 확정한 뒤 서로 다른 적절 수정안 2개 선택 | 판단 전 수정안 노출, 1개·3개 선택 허용 안 함 |
| FixReview | 탈락시킬 교정본을 먼저 고정하고 핵심 실패 원인을 선택 | 두 응답 전 피드백 공개 안 함 |
| MultiJudge | 후보 4개를 각각 과소·적정 범위·과잉으로 분류 | BEST/WORST 순위나 1·2·1 분포를 사전 제시하지 않음 |
| DCT | 관계·부담 정보를 잠시 확인한 뒤 새 사건을 번역·통역 | 별도 맥락 퀴즈를 채점하거나 완료 조건으로 쓰지 않음 |
| 피드백 | 세 층을 한 화면에서 보고 우선 수정 목표에 집중 | 모든 참고 표현을 목록처럼 과다 노출하지 않음 |
| 수정·재확인 | 실제 문장을 고치거나 근거를 남겨 유지하고, 첫 수정본을 한 번 확인 | 문장부호만 바꾼 수정을 인정하거나 자동 피드백을 반복하지 않음 |

모든 MPJ 상단에는 “참고 판정 · 비점수 활동”을 표시한다. 응답은 학습자 성적이 아니라 수행 trace와 문항·UX 검토 자료다.

## 체감 부담 관찰

최종 MPJ는 클릭 판단 10회다.

- Scale4: 1회
- FixChoice: 3회
- FixReview: 2회
- MultiJudge: 4회

문항별 `elapsed_ms`와 전체 `mission_completed.elapsed_ms`, MPJ 합계 시간을 저장한다. 구현 후 실제 미션 수행시간을 확인하고, 체감 부담이 크면 MultiJudge 전수분류를 첫 조정 후보로 삼는다. 현재 단계에서 10회가 저부담이라고 실증되었다고 주장하지 않는다.

## 피드백 표시 규칙

- 의미 충실성, 문법·표현 정확성, 목표 화용 특성을 항상 분리한다.
- 수정 우선순위 층만 펼쳐 보여 주고 나머지는 한 줄 상태로 남긴다.
- 최소 교정은 1개, 다른 전략의 대안은 최대 1개다.
- 별도 참고 표현은 피드백 호출 실패 시에만 최대 2개를 대체 자료로 보여 준다.

## 수정과 재확인

- `revise`: 공백·문장부호·기호를 제거하고도 최초 산출과 달라야 제출할 수 있다.
- `keep`: 피드백이 `clear`가 아니면 유지 이유나 학습자 이견이 필요하다.
- 첫 수정본은 지정 목표 반영, 의미 보존, 새 문제를 한 번만 스캔한다.
- 의미 목표가 아직 남은 상태와 다른 목표 수정 중 새로 생긴 의미 훼손을 구분한다.
- `partial` 또는 `new_problem`이면 한 번 더 고칠 수 있으나 두 번째 스캔은 없다.

## 번역·통역 지원

- 번역: 산출에 필요한 비화용적 내용 어휘·짧은 구를 0~2개 제공할 수 있다.
- 통역: 어휘 힌트 없음, 원문 재생 최대 2회.
- 완화·공손·선택권 등 목표 화용 전략 자체를 힌트로 제공하지 않는다.

## 호환성과 데이터 해석

- 과거 `mission_v1`~`mission_v5`는 기존 의미를 보존해 읽는다.
- 신규 생성은 `mission_v6`만 사용한다.
- 기존 MPJ5 수행행을 소급 변환하지 않는다.
- 과거 `mission_v4`의 후보 4개 전수분류 골격과 현행 FixReview 반복은 구분해 기록한다.
- 동일 세션 초안–수정본 차이는 즉각적 피드백 수용의 관찰값이다. 장기 학습 효과, 능력 향상, 전이 효과를 입증하지 않는다.
