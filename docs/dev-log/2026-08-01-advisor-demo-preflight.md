# 2026-08-01 · 지도교수 점검 전 학습자·관리자 동선 정리

branch `codex/learner-report-v1-2026-07-31` · base `9a244f0`

## 배경

학습자 홈을 없애고 수업 탭을 기본 착지점으로 바꾼 뒤에도, 첫 노란 CTA가 주차 카드를
펼치기만 하고 상세 패널은 3×3 그리드 아래 화면 밖에 열렸다. 지도교수가 직접 로그인해
가장 눈에 띄는 버튼을 눌렀을 때 MPJ 4문항으로 곧바로 이어지지 않는 것이 출시 전 핵심
문제였다. 관리자 화면에는 미구현 메뉴가 남아 있었고, 라운지 홈은 카드별 정보가 많아
세 코너가 한눈에 구분되지 않았다.

## 변경

### 1. 관리자 미완성 메뉴 숨김 — `3e120be`

`pending` 표시가 붙은 수업 자료 생성·학습 분석·연구 데이터 관리·사용자·권한을
사이드바와 모바일 선택 메뉴에서 숨겼다. 라우트와 원래 메뉴 정의는 보존해 구현 완료 뒤
필터만 해제할 수 있다.

### 2. 수업 지도에서 실제 실행 가능한 미션으로 연결 — `6ad1e06`

- 현재 학습은 `nextScenario`가 있는 주차만 후보로 삼고, 일부 완료한 진행 중 주차를
  미시작 주차보다 우선한다. 선정 조건과 실제 「미션 시작」 렌더 조건을 일치시켰다.
- 상단 CTA는 화면 밖 상세 패널을 펼치지 않고 실제 미션으로 직행한다. 준비된 도입 아크가
  있는 경우에만 아크를 먼저 거친다.
- 주차 카드를 직접 누르면 그리드 아래 상세 패널을 화면 안으로 스크롤한다. 배정 없는
  카드는 비활성화하고 `미션 0/0` 대신 콘텐츠 준비 상태만 표시한다.
- 상세 패널은 미완료 미션을 완료 미션보다 먼저 보여 준다.
- 미션 인트로의 노란 시작 버튼을 5단계 목록 바로 아래로 올렸다. 동일 장면이 MPJ에서
  다시 제시되므로 인트로 하단의 중복 「상황」 박스는 제거했다.
- 현재 게시 강좌의 검수 완료 16개가 모두 번역이므로 요약의 `번역과 통역` 문구를
  제거해 편성보다 큰 주장을 하지 않았다.

### 3. 라운지 홈을 코너 선택 화면으로 축소 — `debe8e8`

카드에서 예문 미리보기·관계 배지·긴 설명을 제거하고 아이콘, 제목·배지, 한 문장,
「들어가기」만 남겼다. 1280×720에서 세 코너와 하단 내비가 스크롤 없이 한 화면에
들어오도록 수직 중앙에 배치했다.

### 4. 시연용 번역→통역 연결은 반영하지 않음

검수 완료 시나리오를 실데이터로 조회한 결과 17건 모두 번역이었고, 검수 대기 중급 칭찬
2건도 모두 번역이었다. 동일 장면·검수 완료 통역 미션이라는 전제가 성립하지 않아
미커밋 pairing 실험을 전부 제거했다. 정본인 `MPJ 4 + DCT 1` 단위, 생성계약, 스키마,
저장 필드는 그대로다.
