# 교수자용 오프라인 수업본 HTML

- 날짜: 2026-08-26
- 목표: 승인 미션 기반 수업자료를 로그인·네트워크 없이 교실에서 실행할 수 있는 단일 HTML 파일로 내보낸다.

## 구현

- `/admin/package`에 `오프라인 수업본(.html)` 버튼을 추가했다.
- 현재 선택한 30·50·90분 운영표와 교수자용 6단계 자료를 외부 자원 없는 단일 HTML 파일로 생성한다.
- 90분 구성은 미션 1·2의 각 6단계와 마지막 판단 근거 비교 화면을 함께 내보낸다.
- 파일 안에서 이전·다음, 키보드 화살표, Enter 해설 공개, 인쇄·PDF를 사용할 수 있다.
- 미션 ID·생성 시각·원본과 동기화되지 않는 읽기 전용 사본임을 표시한다.

## 출력 CTA 정리

- 운영 확인 결과 화면 흐름을 그대로 인쇄한 학생 활동지와 교수자 PDF는 페이지 구조와 실제 사용
  목적이 맞지 않아 기본 출력에서 제거했다.
- 남는 실행 경로를 `프로젝터 화면`과 `HTML` 두 버튼으로 단순화했다.
- `프로젝터 화면`을 주 CTA로 두고 툴팁은 `전체 화면 보기`, `HTML`의 툴팁은 `오프라인
  수업본`으로 제공한다.
- 현재 6단계 자료를 화면·HTML이 공유하는 슬라이드형 실행 원본으로 유지하며, 별도 슬라이드 제작
  시스템이나 학생 공유 링크는 추가하지 않았다.

## 안전 경계

- DB·API·인증·학습자 수행 데이터·저장 기능을 포함하지 않는다.
- 학생용 HTML과 익명 공유 링크는 만들지 않았다. 교수자 해설은 파일 소스에 포함되므로 교수자용으로만 명시한다.
- 모든 미션 문자열을 HTML escape하고 외부 URL·폰트·스크립트 의존성을 두지 않았다.
