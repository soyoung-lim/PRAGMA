# 2026-08-30 동료 학습자 응답 공개

## 범위와 결정

- 미션 완료 화면에 `동료 학습자 응답`을 추가했다.
- 공개 단위는 별도 수강 집단 모델 없이 기존 `course_id + mission_id`로 한정했다.
- 흐름은 `응답 수집 중 → 응답 마감 → 학습자에게 공개`다. 마감 시 익명 `MissionPattern`만 스냅샷으로 저장하며 개인 식별자와 이견 원문은 저장하지 않는다.
- 학습자는 본인 미션 완료 뒤에만 RPC로 접근한다. 5명 미만은 집계 중, 공개 전은 교수자 공개 대기, 공개 후에는 익명 분포에 현재 수행의 `내 선택`을 겹쳐 표시한다.
- 공개 화면에는 다수 응답이 정답이 아니라는 성찰 안내를 고정했다. 마감 뒤 재시도는 스냅샷을 바꾸지 않으며, 공개 전 교수자가 명시적으로 `응답 다시 수집`을 선택한 경우에만 새 마감이 가능하다.

## 구현과 검증

- 교수자 보드에 마감·재수집·학습자 공개 제어와 최소 5명 gate를 연결했다.
- 운영 Supabase에 `20260830193000_class_response_release.sql` 한 건을 적용했다.
- 운영 migration history에만 존재하던 `20260829183000_scope_lock_attempt_lineage.sql`은 기존 작업트리의 동일 내용을 저장소에 복원했다. 원격 DB에는 이미 적용된 migration이라 다시 실행되지 않았다.
- 신규 계약·학습자 상태·교수자 보드 표적 **6 tests**와 typecheck가 통과했다.
- 전체 테스트·반복 브라우저 검증·실제 학습자 5명 수행·실제 공개 클릭은 실행하지 않았다.

## 한계

- 현재 공개 단위는 교과목과 미션이다. 별도 분반·수강 집단 모델은 추가하지 않았다.
- 실제 수업에서 5명 이상 완료→마감→공개하는 운영 종단은 교수자 세션에서 확인이 필요하다.
