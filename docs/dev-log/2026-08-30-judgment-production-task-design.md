# 판단·산출 과제 설계 화면 정본화

## 문제

`/admin/question-designer`가 현행 정본과 달리 MPJ 4문항을 설명하고 있었다. 실제 생성 스키마와 학습자 런타임은 `MPJ_TYPE_ORDER_V5`의 다섯 판단 문항과 독립 DCT 1개를 사용한다.

## 변경

- 사이드바와 헤드라인을 `판단·산출 과제 설계`로 통일했다.
- 보조 문구를 `MJT 5개로 맥락별 판단을 연습하고, DCT 1개로 직접 산출하는 학습 구조입니다.`로 확정했다.
- 내부 코드 용어와 순서 정본은 `MPJ`를 유지하고, 관리자 화면에서는 `MJT`와 `DCT`를 사용한다. 영어 전체 명칭은 용어 안내에서 한 번만 표시한다.
- MJT 1~5의 실제 기능, 독립 DCT, 비점수·맥락 의존·의미 보존 원칙, DCT 이후 3층 피드백과 수준별 불변 구조를 설명하도록 본문을 교체했다.
- 구버전 MPJ4·A/B/C 기준답안 중심 설명과 수준별 문항 수로 오해할 수 있는 내용을 제거했다.

## 검증

- `npm.cmd test -- src/pages/admin/AdminQuestionDesigner.test.tsx`: 2 tests 통과
- `npm.cmd run typecheck`: 통과
- `git diff --check`: 오류 없음(CRLF 변환 경고만 확인)

## 범위

- 생성 스키마, DB, 프롬프트, 학습자 수행 흐름은 변경하지 않았다.
- 전체 회귀·production build·브라우저 E2E는 문구·설명 화면 변경 범위에 비해 비용이 커 생략했다.

## 후속 처분

- 사용자 재검토에서 이 화면은 실행·조회·수정 기능이 없는 정적 설명이며 논문·정본 문서와 중복된다고 판정했다.
- 사이드바 항목, `/admin/question-designer` 라우트, 컴포넌트와 전용 테스트를 삭제했다. 내부 MPJ5+DCT1 계약과 생성·검수·학습자 흐름은 유지한다.
- 관리자 내비게이션 표적 3 tests와 typecheck가 통과했다. 삭제 커밋은 `eea653e`다.
