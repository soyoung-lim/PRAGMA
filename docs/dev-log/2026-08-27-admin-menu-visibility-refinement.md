# 관리자 메뉴 기능 가시성 정리

- 날짜: 2026-08-27
- 목표: 관리자 5단계 작업 흐름은 유지하면서 서로 다른 생성 작업을 명시적으로 노출하고, 중복·오해 소지가 있는 메뉴명을 실제 역할에 맞춘다.

## 변경

- 하나의 `AI 시나리오 생성` 메뉴로 표시하던 별도 화면을 `시나리오 개별 생성`과 `시나리오 배치 생성`으로 분리했다. 개별 생성은 조건을 직접 정해 한 건을 완성하고, 배치 생성은 실행 전 분포를 검산한 뒤 여러 건을 만드는 서로 다른 작업이라는 판단을 반영했다.
- `품질관리 현황` 중간 화면은 실질 작업 없이 자동 점검과 교수자 검수 링크·중복 건수만 제공해 제거했다. 기존 `/admin/research-qa`와 과거 전문가 주소는 404가 되지 않도록 자동 품질 점검으로 연결했다.
- 자동 품질 점검의 복귀 링크는 운영 대시보드로, 콘텐츠 개선 후보의 복귀 링크는 운영·품질관리 흐름으로 정리했다. 자동 품질 점검과 교수자 최종 검수·공개 기능 및 데이터는 변경하지 않았다.
- `수업 데이터 백업·복원`은 사용자의 운영 안전 요구에 따라 수업 운영 메뉴에 그대로 유지했다.
- HSK는 수준 판정이 아니라 콘텐츠 감사에만 사용한다는 정본에 맞춰 `HSK 3.0 콘텐츠 감사 기준`으로 바꿨다.
- 이미 구현된 강의계획서·교실 화면·개선 후보의 존재가 메뉴에 드러나도록 `15주 수업 편성·강의계획서`, `수업자료·교실 화면`, `콘텐츠 개선 후보`로 정리했다.
- 생성·편성·수업자료·HSK·개선 후보 화면 제목도 같은 명칭으로 맞췄다. 데이터 구조와 라우트는 변경하지 않았다.
