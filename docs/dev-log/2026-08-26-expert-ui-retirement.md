# 전문가 검토 UI 안전 철거

- 날짜: 2026-08-26
- 목표: 현행 연구설계에 없는 전문가 개별 콘텐츠 승인 기능을 활성 제품 표면에서 제거하되 DB는
  변경하지 않는다.

## 결정

- 전문가 3인의 역할은 PRAGMA 설계·사용성 형성평가이며 개별 콘텐츠 내용타당성 확인·합의·공개
  승인 역할이 아니다.
- 전문가 로그인·검토 대기열·운영 화면과 이를 위한 프런트 전용 계약을 제거한다.
- 과거 전문가 URL은 품질관리 현황으로 이동시켜 깨진 진입점을 남기지 않는다.
- Supabase migration, table, row, RLS, RPC와 서버 측 공개 gate는 이번 작업에서 변경하거나 삭제하지
  않는다. 따라서 이번 변경은 DB 폐기가 아니라 활성 애플리케이션 표면의 안전 철거다.

## 구현

- 전문가 로그인·검토 대기열·관리자 전문가 운영 화면과 미사용 구 품질관리 화면을 삭제했다.
- 전문가 합의·18건 표본·Gold 전문가 검토·업무량 집계를 위한 프런트 모듈과 테스트를 삭제했다.
- 연구자 Gold 자동 회귀와 교수자 검수를 활성 품질 근거로 남기고 사용자 문구에서 전문가 공개
  gate를 제거했다.
- 데이터 기반 콘텐츠 개선 화면은 학습자 이견·자동 회귀·교수자 확인을 중심으로 정렬했다.
- `/expert-login`, `/expert/reviews`, `/expert/gold-reviews`와 구 관리자 전문가 경로는
  `/admin/research-qa`로 리다이렉트한다.
