# 2026-08-03 미션 콜드 오픈 1화면 재설계 (한→중)

## 관찰

- 사용자 지적: 학습자 화면이 "연구자 설문지 같고 딱딱하고 재미없다".
- 콜드 오픈이 2단계(`장면 열기` → `당신 차례`)였는데, 9개 화행 중 **7개가 개시형**이라
  두 번째 단계의 "상대 신호" 자리가 구조적으로 빈다. 실제 화면에는 점선 빈 입력 박스와
  "내가 먼저 번역을 작성할 차례입니다" 한 줄만 남았다.
- 메타 라벨(`오늘의 장면`·`장면 열기`·`상황과 상대를 먼저 확인하세요`·`지금, 직접 번역할
  장면`)이 4겹이고 관계 태그가 3회 반복되어, 포장이 본문(3문장)보다 많았다.
- 초점(target feature)이 노란 카드에 **학습 목표 문장**으로 제시돼 장면의 긴장이
  학습 안내로 바뀌어 있었다.

## 변경

- **2화면 → 1화면.** `MissionColdOpen`의 내부 단계 상태(`useState<"scene"|"turn">`)를 제거했다.
- 암전 패널(`#1B2733`) · 좌측 정렬 통일 · Pretendard 단일(세리프 미도입).
- 제목 = `situation_ko` 첫 문장. `sceneHeadline()`을 신설해 **1인칭 주어만** 제거한다
  (`나는/내가/저는/제가`). 3인칭 서술은 주어가 정보이므로 보존한다.
- 질문 = 「{목표어}로는 어떻게 {화행동사} 좋을까?」. `SPEECH_ACT_VERB_KO` 9행 신설.
  당위형(`해야 할까`)을 쓰지 않는다 — 모범답 하나를 암시해 복수 정답 전제와 충돌한다.
  방향에 따라 목표어를 바꾼다(`ko_zh`→중국어 / `zh_ko`→한국어).
- CTA = 「비슷한 상황 {n}개로 감 잡기」. 알약형·내용 폭. 개수를 노출해 첫 클릭의 문턱을 낮춘다.
- 헤더 우측에 방향·수행 방식(`한→중 번역`)을 추가했다.
- 콜드 오픈에서만 진행 레일의 단계 라벨을 `opacity-0`으로 감춘다. 자리를 남겨 단계 전환 시
  높이가 흔들리지 않게 하고, 화면 낭독기에는 그대로 남긴다.
- 제목에 `break-keep`(word-break: keep-all) + `text-wrap: balance`를 함께 준다.
  balance만 쓰면 "배송지 / 를"처럼 조사가 잘려 어절이 두 줄로 쪼개진다.
- 선행 발화(`preceding_turn`) 블록은 **콜드 오픈에서 표시하지 않는다.** 장면을 흐리고,
  DCT 수행 화면에서 원문과 함께 제시되므로 정보 손실이 없다. `classifyColdOpen`은
  QA용 `data-cold-open-kind` 속성과 결측 경고 근거로 유지한다.

## 🔴 채택하지 않은 것 — 대역 축 노출

초안은 `band_schema` 양극단 라벨을 조립해 "밀어붙이면 부담이고, 돌려 말하면 흐지부지된다"를
표시하려 했다. **철회했다.**

1. MPJ는 Scale4(첫인상) → FixChoice(correction 공개) → Reason → MultiJudge로 대역 축을
   단계적으로 공개하도록 설계돼 있다. 콜드 오픈에서 축을 말하면 Scale4가 재는 것이
   첫인상이 아니게 된다.
2. "돌려 말하면 흐지부지된다"는 '간접적이면 모호하다'는 소박한 규칙을 설치한다. 중국어에서
   상위자 대상 직접성은 오히려 적정할 수 있어(Yu 1999) 카탈로그 `counter_rule_note`가
   깨려는 방향과 충돌한다.
3. 산출 전 강조를 제거하고 사후 공개로 옮긴 선례(`3c52299`)와 배치된다.

대신 **판단에 필요한 상황 사실**(매체·선행 대화 유무·상대의 선택권)만 맥락 줄에 둔다.

## 범위·미완

- **한→중 한정.** 학습자 도달 가능 미션 16건이 전부 `ko_zh`다. 중→한은 "남의 말을 어떻게
  옮기는가"라 주어가 흔들려 문형을 따로 설계해야 한다.
- 제목이 아직 `situation_ko` 첫 문장(3인칭·장문)이다. 30자 이내 당사자 시점 한 줄은
  `hook_ko` 필드 신설이 필요하며 **생성계약·스키마 게이트 별건**이다. 필드가 생기면
  제목 출처 한 줄만 교체하면 되도록 두었다.
- DB·스키마·프롬프트·생성 콘텐츠·판정 로직·`revision_scope`·완료 조건·`POLICY_VERSION`은
  변경하지 않았다. 콘텐츠 재생성도 없다.
- 이 커밋에는 직전 worktree에 미커밋으로 남아 있던 sticky 헤더 블록 위치 이동분이 함께
  들어간다. 렌더 결과와 테스트로 확인했으며, 폐기된 2화면 콜드 오픈 시안은 포함되지 않는다.
