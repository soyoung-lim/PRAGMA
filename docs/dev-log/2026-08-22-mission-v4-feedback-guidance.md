# 2026-08-22 · Mission V4 피드백·다듬기 행동 안내 개선

## 수행한 변경

- DCT 제출 전에 한자 문자가 없거나 지나치게 짧은 입력을 구분해, 비어 있는 답안과 `ㅋㅋㅋㅋ` 같은 명백한 비중국어 입력이 피드백 단계로 넘어가지 않게 했다.
- 피드백 화면은 세 기준을 동시에 전면 노출하지 않고, `수정 필요`·`보완 권장` 순으로 가장 중요한 기준 한 가지를 먼저 보여 준다. 의미·문법·화용 전체 진단은 접어서 필요할 때 펼칠 수 있게 했다.
- 문제 구간·수정 방향·참고 문장을 하나의 피드백 surface 안에서 구분선으로 연결해 카드 중첩을 줄였다.
- 수정 입력 바로 위에 접이식 `원문·상황 다시 보기`를 두고 관계·채널·P·D·R은 접힌 상태에서도 보이게 했다. 펼치면 상황, 한국어 원문과 첫 번역을 함께 확인할 수 있다.
- 보완이 필요한 답안은 실제로 한 곳 이상 수정한 뒤에만 `수정안 확정하기`가 활성화된다. 수정이 필요 없는 답안은 최초 번역을 그대로 확정할 수 있다.
- 오답·WORST의 빨강과 권장·BEST의 초록은 그대로 유지했다.

## 후속 화면 검토 반영

- `이유 찾기`의 짧은 자유입력은 유지했다. 선택형 근거로 되돌리지 않고, 완성형 한국어가 거의 없거나 같은 글자만 반복한 답은 제출하지 못하게 했다.
- 근거 입력 바로 위에 중국어 판단 대상과 `내 판단`을 다시 보여 주고, 정답을 노출하지 않는 문장 시작 도움을 추가했다.
- 피드백 화면의 순서를 `최우선 문제 → 바꾸는 방법 → 수정 입력 → 세 기준 상세·기억할 점`으로 바꿔 수정 행동을 앞당겼다.
- 열 개 내부 화면을 세 구간으로 나누는 진행바를 먼저 실험했으나, 구간 라벨과 피드백 전용 항목이 사이드바를 더 복잡하게 만들어 후속 검토에서 철회했다.
- 완료 후 과거 단계를 열면 `n단계 기록 검토 중`과 완료 화면 복귀 버튼을 보여 줘, 새 문제를 다시 푸는 화면과 구분했다.

## 학습 과제 진행 표시 재분류

- 의미·문법·화용 피드백 화면과 응답 기록은 삭제하지 않고 각 DCT의 내부 과정으로 재분류했다.
- 사이드바에는 학생이 실제로 수행하는 여덟 과제만 표시한다: `판단하기`·`상황 비교`·`고쳐 보기`·`이유 찾기`·`BEST·WORST`·`첫 상황 번역`·`상황 변화 판단`·`바뀐 상황 번역`.
- 두 번역 과제는 피드백·수정이 끝난 뒤에만 완료된다. 번역 화면 안에는 `작성 → 피드백 확인 → 수정·확정`의 작은 내부 진행 표시를 추가했다.
- 과제 번호 원형은 36px에서 32px로 약 11% 줄였고, 기존 구간 라벨은 모두 제거했다.
- 개발자 바로 이동용 내부 화면 ID 열 개는 프리뷰 검증을 위해 유지했다.

## 논문 시연 관점 재검토와 10단계 복원

- 여덟 과제 투영은 학생용 사이드바를 단순화했지만, 논문 캡처와 디펜스에서는 두 번의 `번역 산출 → 3기준 피드백 → 수정` 순환에서 피드백 개입이 보이지 않는 문제가 있었다.
- 피드백·수정 화면을 다시 독립된 학습 단계로 표시해 열 단계를 복원했다. 내부 활동과 응답 구조는 변경하지 않았다.
- 단계명은 `판단하기`·`상황 비교`·`고쳐 보기`·`이유 찾기`·`BEST·WORST`·`번역 실습 1`·`피드백·수정 1`·`바뀐 상황 판단`·`번역 실습 2`·`피드백·수정 2`로 정리했다.
- 구간 제목과 구분선은 다시 넣지 않았다. 6번과 8번 앞에 미세한 여백만 두고, 현재 단계에만 옅은 노란 행 배경을 적용했다.
- 32px로 축소한 번호 원형은 유지하고 연결선은 1px로 낮췄다. 완료·현재·미래 상태만 노랑·네이비·회색으로 구분한다.
- 열 단계와 중복되던 DCT 내부 `작성 → 피드백 확인 → 수정·확정` 진행 표시는 제거했다.

## 노란색 역할 정돈

- 노랑을 다목적 상태색에서 `현재 단계의 얇은 링`과 `실제로 확인할 학습 표현` 중심의 주의색으로 좁혔다.
- 사이드바의 완료 연결선은 회청색, 현재 행은 중립 회색으로 정리했다. 후속 화면 검토에서 완료 원형까지 중립화하면 진행 보상이 지나치게 밋밋해져, 완료 원형의 노란 채움과 네이비 체크는 복원했다. 현재 단계는 네이비 원과 얇은 노란 링을 사용한다.
- 피드백·수정과 상황 변화 화면의 큰 노란 배경은 흰색·크림색 surface와 구분선으로 바꿨다. 노랑은 작은 아이콘, 왼쪽 accent, 보완 권장 배지와 목표 표현 밑줄에 남겼다.
- 번역문 전체가 피드백 대상으로 잡힌 경우에는 문장 전체를 노란 면으로 칠하지 않고 노란 밑줄만 사용한다.

- localhost에서 7단계 피드백·수정과 8단계 바뀐 상황 판단의 색 위계를 다시 확인했다: PASS.

## 이유 찾기·BEST/WORST 후속 밀도 조정

- `이유 찾기`에서 선택을 잠근 뒤 중국어 판단 대상과 내 판단을 다시 보여 주던 카드를 제거했다. 바로 위의 언어 카드와 선택지를 스크롤해 확인할 수 있어 중복 정보로 판단했다.
- BEST/WORST 선택 전 카드의 두 선택 버튼과 결과 카드의 역할·내 선택 배지를 우측 열로 옮겼다. 중국어 후보가 왼쪽에서 끊김 없이 이어지고, 결과에서는 후보 바로 아래에 설명이 붙도록 했다.
- 결과 배지 열은 임의 최대폭과 줄바꿈을 제거하고 `max-content` 단일 행으로 확보했다. 데스크톱에서는 역할 배지와 내 선택 배지가 세로로 갈라지지 않으며, 좁은 화면에서는 배지 묶음 전체만 본문 아래로 이동한다.
- `바뀐 상황 판단`의 긴 제목·메타 설명·두 실습 비교를 제거했다. `바뀐 조건`과 실제로 달라진 P·D·R 값만 한 줄로 남기고 상황·번역안·판단 문항을 바로 이어 붙였다.
- localhost에서 `판단 대상` 중복 카드 부재, 완료 원형의 노란 채움, BEST/WORST 선택 버튼·결과 배지의 우측 배치, 8단계의 한 줄 조건 진입을 확인했다: PASS.
