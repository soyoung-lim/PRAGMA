# 학습자 교과목·주차 학습 위계 연결

- 날짜: 2026-08-27
- 목표: 로그인한 학습자가 공개 교과목을 선택하고 15주 계획에서 주차별 A·B 미션으로 이어지게 한다.

## 구현

- `/learner/course`: 공개 교과목 목록과 각 교과목의 수준·모드·방향·주제를 표시한다.
- `/learner/course/:courseId`: 선택 교과목의 15주 계획과 현재 학습 진입점을 표시한다.
- `/learner/course/:courseId/week/:weekNo`: 해당 주차의 도입·학습노트·A·B 미션을 한곳에 연결한다.
- 미션 진입 쿼리에 교과목·주차를 보존하고 완료 화면에서 해당 주차로 돌아갈 수 있게 했다.
- 기존 비스코프 도입·학습노트 URL은 호환 경로로 유지했다.

## 범위

- 기존 공개 교과목·주차·배정·미션·수행 로그만 읽는다.
- 현행 세 교과목을 승인 학습자 모두에게 제공하므로 수강등록·과목별 권한 테이블을 추가하지 않았다.
- 한 주에 미션이 하나뿐이면 B세트는 준비 중으로 표시한다. 콘텐츠를 임의 생성하거나 편성을 바꾸지 않았다.

## 운영 화면 사용자 피드백 교정

- 최초 배포본의 자동 `이번 학습` 추천과 단계별 3열 카드가 15주 강의계획보다 특정 미완료 주차를
  과도하게 강조한다는 사용자 판정을 반영했다.
- 교과목 상세는 추천 배너와 단계 그룹을 제거하고 1→15주를 한 열의 시간 순서로 표시한다.
- 정본 구성을 `화행 학습 9주 + 메타화용 2주(7·14주) + 고부담 실전 1주(13주)`로 명시했다.
- 기존 운영 교과목의 16개 미션은 실제 화행에 따라 정본 주차로 이동하는 migration을 추가했다.
  콘텐츠는 삭제·재생성하지 않으며, 13주는 서로 다른 두 화행의 검수 완료 고부담 미션이 실제로
  편성되기 전까지 `편성 준비 중`으로 표시한다.
- 검증은 변경 범위에 맞춰 typecheck와 `standard15week.test.ts` 3 tests로 종료했다.
