# 관리자 아카이브 라우팅과 용어 정리

## 변경

- 사이드바의 `시나리오 아카이브`가 코어 라이브러리로 이동하던 리다이렉트를 제거했다.
- 현행 `scenarios` 구조에서 `archived_only`·`excluded` 자료를 구분해 조회하는 읽기 전용 아카이브를 추가했다.
- 코어 라이브러리와 학습 미션 조립의 메뉴와 라우트를 분리했다.
- 관리자 메뉴명과 화면 제목을 논문 제1장의 용어인 학습 콘텐츠 제작, 품질 관리, 교수자 검수·승인, 학습자 수행 기록에 맞춰 정리했다.
- 같은 화면으로 이동하던 커리큘럼 구조와 주차별 편성 메뉴는 `15주 교과목·학습 미션 편성`으로 통합했다.

## 검증

- `npm.cmd run typecheck`: 통과.
- 변경 파일 ESLint는 `AdminResearchQa.tsx`의 기존 `no-explicit-any` 1건 때문에 실패했다. 이번 변경 줄과 무관하다.
- 로컬 production build는 샌드박스가 상위 경로를 읽지 못해 prompt snapshot 단계에서 중단됐다. Railway 빌드와 운영 화면에서 최종 확인한다.

## 연구 기록

- 기능·데이터 계약은 바꾸지 않았다. 라이브러리와 아카이브의 역할을 분리하고 논문 용어와 관리자 화면 표현을 정합화한 UI·정보구조 수정이다.
