# 중→한 번역 정식 학습 경로 잠금

## 시작 문제

- 생성기는 `zh_ko` 방향을 입력받을 수 있었지만 일부 legacy·코어·미션·검수·피드백 프롬프트가
  한→중 표현과 중국어 목표어 판정에 고정돼 있었다.
- 정본 런타임은 번역 미션이어도 `ko_zh`만 허용해, 생성된 중→한 mission_v5를 동일한
  MPJ5+DCT1 학습 흐름으로 수행할 수 없었다.
- 중→한 번역의 학습자 역할, 원문 화행 보존, 자연스러운 한국어 관계 실현과 과잉 공손성·길이
  편향을 생성·수리·검수·피드백 전 구간에서 같은 기준으로 고정할 필요가 있었다.

## 변경

- 중→한 번역을 통역과 분리하고, 학습자를 제3자 번역자가 아닌 자기 발신 상황의 화자로 고정했다.
- 코어·legacy 시나리오·mission_v5·후보 생성/검사·국소 수리·코어/미션 품질검사·관계적 피드백
  감사·학습자 피드백에 다음 계약을 연결했다.
  - 중국어 원문의 명제, 지정 화행 목적, 태도와 화용적 힘을 보존한다.
  - 실제 관계·채널·장르에서 자연스러운 한국어 담화로 실현한다.
  - 중국어 어순과 불필요한 주어 반복·명사화·직역 결합을 번역투로 검사한다.
  - 일반 문법 교정, 과잉 존대·사과·감사, 더 긴 표현을 우수성 근거로 삼지 않는다.
- 기존 결함 코드와 MPJ5+DCT1 topology를 유지했다. 학습 흐름은
  `scale4 → judge3 → fix_choice → reason → multi_judge → DCT`이며, 판단 토폴로지는
  `X → A → A → A → Y → C`다.
- 정본 런타임이 `zh_ko + translation`을 받아 방향 표기와 DCT 목표어를 한국어로 투영하도록 했다.
  통역 미션 차단은 유지했다.
- 후보 생성·검사·수리와 릴리스 프롬프트 버전을 중→한 계약 버전으로 올리고, 프런트 fallback,
  SQL inventory, 프롬프트 스냅샷 29종과 Edge 검수 번들을 동기화했다.
- 생성 계약 정본과 학습자 구조 정본에 역할·등가·자연성·토폴로지 경계를 반영했다.

## 검증

- 관련 런타임·프롬프트 회귀검사: **2 files, 21 tests 통과**.
- 전체 회귀검사: **117 files 통과, 3 files 스킵 / 699 tests 통과, 9 tests 스킵**.
  첫 전체 실행은 worktree에 `.env`가 없어 Supabase client 수집 10개가 중단됐으며, 저장소 `.env`를
  출력하지 않고 테스트 프로세스에만 주입해 재실행했다.
- `npm.cmd run typecheck`: 통과.
- `npm.cmd run prompts:verify`: 결정성 스냅샷 2종 통과. 첫 실행의 상위 의존성 접근 제한은
  허용된 환경에서 동일 명령을 재실행해 해소했다.
- 변경 파일 ESLint: 통과. 저장소 전체 lint는 이번 변경과 무관한 기존 오류 34건·경고 12건이
  남아 있어 전체 green은 아니다.
- `npm.cmd run build`: 통과, prebuild의 production source 정책·프롬프트 스냅샷·Edge 검수 번들
  검증과 Vite **1,967 modules** 변환 완료. 첫 build가 오래된 검수 번들을 감지해 제공된
  `review:bundle` 명령으로 재생성한 뒤 통과했다. 기존 CSS 구문·500 kB 청크 경고는 남아 있다.
- `git diff --check`: 공백 오류 없음(CRLF 변환 안내만 있음).

## 운영·데이터 경계

  검증 과제다.
