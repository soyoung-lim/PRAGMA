## 작업명과 목적

최신 `mission_v4` 학습 화면에서 장면 몰입감, 상대의 존재, MPJ2의 순차 공개, MPJ3 오류 신호, MPJ4 비교 응답과 직접 표현 힌트 정책을 사용자 검토 결과에 맞춘다. 구버전 서버를 최신으로 잘못 안내한 원인을 확인하고, 실제 최신 기준선에서 수정안을 다시 구현한다.

## 구현한 것

- MPJ 장면 카드와 직접 번역·통역 장면 카드의 밀도를 하나로 통일했다. 고정 최소 높이는 제거하고 데스크톱 상하 18px, 문장 간격 6px, 행간 1.58을 공통 적용해 내용 길이에 맞게 줄어들도록 했다.
- 미션 본문에 일괄 적용되던 `pb-24`를 제거해 마지막 동작 아래의 96px 추가 여백과 불필요한 스크롤을 없앴다. 공통 shell의 24px 마감 여백은 유지했다.
- mission_v4의 네 MPJ에 target-language `preceding_turn`을 필수화했다. 2차 검토에서 별도 `오늘` 구분은 삭제했다.
- 강제 인사말은 넣지 않았다. 선행 발화가 복원된 대화는 이미 진행 중인 스레드이므로 첫 인사를 일괄 삽입하지 않는다.
- MPJ1의 `판정 기준 보기`를 참고 판정의 지위와 확인 범위 두 문장으로 축약하고 Scale4 질문을 `이 번역안은 이 상황에 얼마나 적절한가요?`로 수정했다.
- MPJ2는 Judge3 제출 뒤 correction을 공개하도록 순차 흐름을 유지·검증했다.
- MPJ3의 부적절 전제 안내를 빨간 테두리·적색 배경·경고 아이콘으로 강화했다.
- MPJ3의 두 오답을 target에 실제로 보이는 요소와 인접 화용 쟁점에 관한 그럴듯한 해석으로 교체하고, 정답 위치 비고정·황당한 오답 금지 규칙을 생성 프롬프트에 추가했다.
- MPJ4는 5후보를 유지하되 한 화면에서 각 후보 오른쪽의 `BEST`·`WORST` 태그로 하나씩 고르고, 제출 뒤 다섯 후보의 참고 대역과 설명을 공개하도록 변경했다.
- 생성 스키마·결정론 규칙·Edge 생성 프롬프트를 과소 2·적정 2·과잉 1의 5후보와 전 MPJ 선행 발화에 맞췄다.
- 한→중 번역에는 비화용적 내용 어휘 힌트 정확히 2개만 한 줄 패널로 제공하고 열람 여부·최초 시각을 비채점 trace로 저장한다.
- 통역에는 첫 수행과 재도전을 포함해 힌트를 제공하지 않는다.
- 번역 어휘 힌트 패널은 전체 폭이 아니라 내용 길이에 맞게 줄어들도록 변경했다.
- 워크플로우 단계명을 `표현 감각 익히기 → 직접 번역하기/직접 통역하기 → 피드백 확인하기`로 변경했다.
- 번역 장면 신호를 통역 장면과 같은 문장 구조인 `지금, 직접 번역할 장면`으로 통일했다.
- 번역 입력칸과 다듬기 입력칸의 초기 높이를 학습자 수준에 따라 입문 2행·중급 3행·고급 4행으로 맞추고, 더 긴 답안은 세로 확장해 입력할 수 있게 유지했다.
- 피드백의 의미·문법·상황 적절성 3개 판정 카드는 문구를 유지한 채 최소 높이를 104px에서 88px로 줄이고 상하 여백을 압축했다.
- MPJ 4개 뒤 기존 handoff를 실제 응답 기반의 개인화 SUMMARY로 확장했다. 네 문항을 `첫인상 판단 / 판단하고 고쳐보기 / 이유 찾기 / 여러 초안 비교`로 정리하고, 활동 완료 문구가 아니라 이번 장면에서 확인한 판단 기준을 한 줄씩 남긴다. 참고 판정과 다른 행만 수업 비교를 안내하고, 중복되는 하단 흐름 문장은 삭제했다.
- 다듬기 화면은 긴 피드백 문단을 반복하지 않고 판정 결과에서 도출한 한 줄 수정 행동을 표시한다. 완료 화면도 일반 미션 설명 대신 실제 피드백과 수정 여부에 맞춘 한 줄 조언을 표시하며, 피드백이 없을 때만 일반 원칙 한 줄을 사용한다.
- v4 미리보기에서 번역 뒤 통역으로 전환할 때 `preview=v4`와 part 정보를 보존해 구버전 샘플이나 로그인 화면으로 이탈하지 않게 했다.
- `로그인 없이 둘러보기` 상태가 탭별 `sessionStorage`라 새 탭 검토 링크에서 사라지는 원인을 확인했다. 일반 학습 인증은 유지하고, DEV의 명시적 `/learner/practice?preview=v4`만 인증 가드를 통과하도록 수정했다.
- `CLAUDE.md`와 `AGENTS.md`에 공통 연구·개발 기록 지침을 추가했다.
- 생성계약·학습자구조·관리자구조 정본과 `docs/research-trail`을 현재 결정에 맞췄다.
