# 전체 설계도의 통합 워크플로우 정렬

- 날짜: 2026-08-07
- 범위: `/architecture` 심사 설명용 화면의 문구와 시각 연결만 변경

## 변경

- 화면 제목을 `PRAGMA · 통합 워크플로우`로 정리하고 기존 3열 구조와 MPJ4+DCT1 흐름은 유지했다.
- ③ 연구·평가·설계 열을 실제 구현 상태에 맞게 구체화했다. 수행 로그·학습자 이견·설계 추적은 현재 기능과 기록 범위를 설명하고, 전문가 형성 평가는 `연구 예정`, 연구 데이터 내보내기는 `준비 중`으로 표시했다.
- 전문가 형성 평가를 `외부 전문가 3인 · 대표 미션 독립 평가`로 바꾸고, 구현되지 않은 `승인 루브릭 · 이중 평정` 표현을 제거했다.
- 각 열 제목은 별도 색상 밴드 없이 번호 원과 굵은 제목으로 강조하고, 부제 시작점을 제목에 맞춰 정보 위계를 분명히 했다.
- 세 연결어를 `승인 미션`·`학습 데이터`·`개선안 반영`으로 정리했다. 첫 연결자는 승인 행위가 아니라 다음 단계로 넘어가는 대상을 표시한다.
- ③에서 ①로 돌아가는 경로를 U자형 복귀 화살표와 기존 인계 화살표와 같은 노란 연결 토큰으로 표시했다.
- 하단 복귀 화살표의 높이를 4px 줄이고 `개선안 반영` 토큰을 3px 위로 올려 720px 화면 하단 안에 여유 있게 수납했다.
- 데스크톱에서는 헤더 아래 영역을 viewport 높이에 맞추고 열 내부 여유를 균등 배분해, 높이가 다른 화면에서도 도식이 위로 몰리지 않도록 했다.
- 학습자 열의 폭을 줄이고 미션 5단계를 중앙에 조밀하게 묶으면서, 1280×720 화면을 스크롤 없이 채우도록 조정했다.
- 최종 열 폭을 `243 / 393 / 251px`로 맞춰 ①은 유지하고 ②를 아주 소폭 줄인 만큼 ③을 늘렸다. 중앙 우선순위는 약 `1 : 1.62 : 1.03`으로 보존했다.
- 미션 단계 문구를 `상황 이해`·`표현 비교`·`번역·통역`·`피드백 검토`·`다듬기`로 정리해 좁아진 ②열에서도 한 행을 유지했다.
- 카드 사이 아래 화살표의 크기·굵기·대비를 높여 세 열의 위→아래 흐름이 목록보다 먼저 읽히도록 했다.
- `학습 수행 로그`를 `학습 수행 기록`으로 바꿔 `학습 기록` 용어와 정렬했다.
- 콘텐츠 검수 절차를 `GPT 품질 점검(생성 결과 1차 점검) → Claude 교차 검증(독립 비판 검토) → 교수자 최종 승인`으로 분리했다. GPT review 프롬프트·실행 경로는 구현돼 있지만 Claude 배치 검증은 연구 절차로 남아 있어 Claude 카드에만 `연구 예정`을 표시했다.
- ③열의 운영 원칙을 `교수·학습 운영과 연구 분석을 분리`로 구체화했다.
- `상황 이해`, `번역·통역`, `피드백 검토`, `다듬기`, `승인 미션만`, `예습·복습용 · 주차 목표와 상황 판단 기준`으로 합의 문구를 정리했다.
- 별도 `다른 상황에 응용` 카드는 추가하지 않았다. 현행 정본은 DCT를 같은 P·D·R의 새 사건으로 규정하며, 관계·매체를 바꾸는 별도 전이 흐름은 정본 라우트에서 은퇴한 목업 코드에만 남아 있어 현행 단계처럼 표시할 근거가 부족했다.
- 실제 수업 운영을 반영해 `학습 기록 → 결과 비교·수업 토론`을 추가했다. 수행 결과·이견·수정 사례를 교수자와 학습자가 함께 비교하는 단계이며, 자동 집단 분석 기능으로 오인되지 않도록 `수업 운영` 상태를 표시했다.
- ①열 부제를 `화행 9종 × 입문·중급·고급 × 주제` 한 줄로 정리하고, 아래 `교수자 최종 승인` 카드와 중복되던 공개 결정 문구를 제거했다.
- DB, schema, 학습자 흐름, 관리자 구조와 다른 앱 화면은 변경하지 않았다.

## 검증

- `npm.cmd run typecheck` 통과.
- `npm.cmd exec eslint -- src/pages/Architecture.tsx` 통과.
- production build 통과(1,903 modules). 최초 샌드박스 실행은 상위 경로 읽기 제한으로 실패했고, 같은 Vite build를 승인된 권한으로 재실행해 통과했다.
- 인앱 브라우저에서 데스크톱 렌더, 모바일 적층, 필수 문구·상태 배지·피드백 연결, 홈 링크를 확인했다.
- 1280×720에서 페이지 스크롤 없이 전체 구조가 한 화면에 들어오고, 미션 5단계가 한 행에 유지됨을 확인했다.
- 데스크톱·모바일 모두 수평 overflow가 없고 브라우저 console error가 없음을 확인했다.
- `git diff --check` 통과.

## 연구 기록 경계

- 새로운 학습설계·평가 방식·데이터 구조를 결정한 작업이 아니라, 이미 확인된 구현 상태와 연구 계획을 심사 설명 화면에 과장 없이 반영한 작업이다.
- 따라서 별도 DEC/ITER/EVD를 추가하지 않고 dev-log에만 남긴다.
