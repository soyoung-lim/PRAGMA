# 라운지 Scope Lock 정본 정렬

## 문제

- 현행 코드는 학습자 하단 메뉴를 `수업 | 기록`으로 운영하고 라운지 경로를 수업으로
  리다이렉트하지만, 학습자 구조 정본은 여전히 `수업 | 기록 | 라운지`와 탭 노출·배포 완료를
  현재 사실로 적고 있었다.
- 라운지는 2026-08-29 Scope Lock에서 데이터와 소스를 삭제하지 않고 운영 범위에서 비노출하기로
  이미 결정했다(`DEC-20260829-01`).

## 변경

- 학습자 최상위 정보구조를 현재 코드와 같은 2탭 `수업 | 기록`으로 정렬했다.
- `/learner/lounge`와 세 하위 경로가 현재 `/learner/course`로 돌아간다는 운영 경계를 명시했다.
- 라운지 3코너는 삭제된 현행 기능이 아니라 소스가 보존된 후속 확장안이며, 현재 연구 구인·핵심
  학습 흐름·운영 범위에는 포함되지 않는다고 구분했다.
- 완료·미완 범위에서 탭 노출 완료 주장을 제거하고, 소스 보존·비노출 상태와 향후 재활성화 게이트를
  분리했다.

## 검증

- 정본 안의 `3탭`, `수업 | 기록 | 라운지`, `탭 노출·배포 포함`, `main 배포에 포함` 잔존 문구를
  검색했다.
- `LearnerBottomNav.tsx`의 2탭과 `App.tsx`의 라운지 redirect를 정본 서술과 대조했다.
- 문서 전용 변경이므로 자동 테스트·빌드는 실행하지 않았다.

## 기록 범위

- 새 설계 결정이 아니라 기존 `DEC-20260829-01`과 현행 코드를 뒤늦게 정본에 반영한 정합성 수정이다.
- 같은 결정을 중복 기록하지 않기 위해 `docs/research-trail`은 갱신하지 않았다.
- 라운지 소스 삭제, 기능 복원, 라우트 변경, 배포는 수행하지 않았다.
