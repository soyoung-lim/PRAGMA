# Mission V4 이유 3지선다 정렬

## 문제

- Mission V4의 A4 `이유 찾기`는 판정 뒤 이유를 자유서술하게 해, 정본 생성계약과 학습자 구조 문서가 규정한 `이유 3개 중 1개 선택` 흐름과 어긋나 있었다.
- 자유서술은 매주 두 미션에서 쓰기 부담을 키우고, 화용적 근거 구별보다 문장 작성 능력의 영향을 더 받을 수 있었다.
- 판정과 이유를 한 번에 처리하거나 이유 선택 전에 참고 판정을 공개하면 최초 판단과 근거 선택을 분리해 기록하기 어려웠다.

## 변경

- A4를 `판정 선택 → 이 판단으로 정하기 → 이유 3개 중 1개 선택 → 이유 확인 → 짧은 피드백` 순서로 바꿨다.
- 판정 잠금 전에는 이유를 숨기고, 이유 확인 전에는 참고 판정과 정답 이유를 공개하지 않는다.
- 이유 후보를 `primary`, `pragmatic_misconception`, `meaning_grammar_context` 세 종류로 명시하고 정답을 `acceptedReasonId`로 위치와 분리했다.
- 코어 응답은 `{ judgment, reasonId }`로 제한했다. 자유서술 `reasonNote`와 확신도 입력은 추가하지 않았다.
- 오답 뒤에는 선택한 이유와 권장 이유를 함께 보여 주고, 정답 뒤에는 한 문단의 짧은 피드백을 제공한다.
- 모바일에서 긴 이유와 `내 선택`·`권장 답안` 배지가 같은 줄의 폭을 경쟁하던 문제를 확인해 작은 화면에서는 배지를 다음 줄로 배치했다.

## 검증

- A4 계약·상호작용 회귀 테스트 2건을 추가했다.
- 전체 Vitest: 72개 파일 통과·3개 파일 건너뜀, 445개 테스트 통과·9개 건너뜀.
- `npm.cmd run typecheck`: 통과.
- 프로덕션 빌드: 1,942 modules, 성공. 기존 Browserslist 갱신 안내와 CSS minifier 경고는 유지됐다.
- 변경 파일 ESLint: 오류 0건. MissionRunV4의 기존 `useEffect` 의존성 경고 1건은 이번 변경과 무관하게 유지됐다.
- localhost에서 데스크톱과 390×844 모바일 뷰를 확인했다. 이유 잠금 전 비노출, 단일 선택, 정답·오답 피드백, 모바일 배지 줄바꿈을 확인했다.

## 범위와 주장 경계

- 이번 변경은 정적 최신 UX인 Mission V4와 미리보기 데이터의 정본 계약 정렬이다.
- `/learner/practice/:scenarioId`의 DB 기반 Mission V1, 라우팅, 저장 스키마, 수행 이벤트, DB migration, Railway 배포는 변경하지 않았다.
- 이유 3지선다의 학습효과를 검증한 것이 아니다. 실제 미션 데이터·저장·분석 계약으로 확장한 뒤 학습자 점검을 수행해야 한다.

## 운영 runner·수행 로그 후속

- DB 기반 Mission V1의 현행 `reason`도 `최초 대역 판단 → 판단 잠금 → 이유 3지선다 → 피드백` 순서로 맞췄다.
- `mpj_response_v1.responses[]`의 같은 문항 trace에 `band_code`, `reason_id`, `reason_kind`를 분리 저장한다. confidence는 계속 만들지 않는다.
- 기존 `learner_mission_logs` 행 안에서 최초·수정 산출, `feedback_v1`, MPJ trace와 `learner_dissent`가 서로 덮어쓰지 않는지 통합 테스트로 확인했다. 새 컬럼과 migration은 필요하지 않았다.
- 운영·미리보기 Reason 및 로그 표적 테스트 12/12와 typecheck가 통과했다. 효율 범위를 지키기 위해 전체 테스트·빌드·브라우저 재검증은 실행하지 않았다.
- V4 샘플은 MPJ5 화면이고 현행 `mission_v5`는 MPJ4이므로 `/learner/practice/:scenarioId`를 V4로 교체하지 않았다.

## MPJ5 최신 설계 정본 교정 후속

- 사용자 승인에 따라 localhost Mission V4의 MPJ5+DCT1를 최신 학습설계로 확정했다. 운영 `mission_v5` MPJ4는 설계 기준이 아니라 후속 동기화가 필요한 과도기 구현이다.
- 다섯 MPJ는 `첫인상 판단 → 맥락 대비 판단 → 판단하고 고쳐보기 → 이유 찾기 → 여러 초안 비교`로 고정했다.
- 한 주의 두 미션은 각각 최초 진입 때 3단 장면 도입을 필수로 한다. 미션 B는 A와 달라진 상대·거리·부담·채널의 관찰 가능한 사실만 보여 주며 답의 방향은 누출하지 않는다.
- 상단 진행은 `장면 이해 → 표현 판단 → 직접 산출 → 피드백 → 다듬기`의 5단 macro progress로 고정하고, MPJ 내부는 `표현 판단 n/5`로 표시한다.
- 이번 후속은 `AGENTS.md`, 정본 3종, 정본 경로 안내와 research trail만 수정했다. 코드·DB·스키마·프롬프트·배포는 변경하지 않았다.
