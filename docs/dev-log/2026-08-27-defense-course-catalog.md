# 디펜스용 3개 교과목 카탈로그 정렬

- 날짜: 2026-08-27
- 목표: 학습 콘텐츠를 미리 생성하지 않고, 디펜스에서 실제 작동시킬 세 교과목의 메타정보와 15주 운영 구조를 확정한다.

## 구현

- 학습자에게 다음 세 교과목만 표준 디펜스 강좌로 노출한다.
  - `AI 기반 한중 화용 통번역 실습`: 중급·한→중·번역 6주+통역 6주
  - `AI 기반 한중 비즈니스 커뮤니케이션`: 고급·한→중·번역 10주+통역 2주
  - `AI 기반 중한 실전 번역`: 중급·중→한·번역 12주
- 각 과목에 확정된 도메인·주제 메타정보를 연결하고 관리자 빠른 프리셋에도 같은 수준·방향·주제를 적용한다.
- 수행모드 분모를 화행 9주가 아니라 OT·중간·기말을 제외한 실제 학습 12주로 정정한다.
- 세 과목의 공통 15주 구조를 `1주 OT → 2~6주 화행 → 7주 중간 메타화용 → 8주 중간 점검 → 9~12주 화행 → 13주 고부담 맥락 → 14주 종합 메타화용 → 15주 기말 점검`으로 고정한다.
- 학습자 교과목 카드에 수준·방향·도메인·주제·번역/통역 주차 수를 표시한다.
- 주차 미션은 실험쌍이 아닌 같은 화행의 독립 완전 미션 `1·2`로 표시한다.
- 운영 DB 적용용 migration을 추가하되 새 미션·수업자료·주차 배정은 생성하지 않는다.

## 범위

- 기존 공통 생성기·편성·미션 수행·수업자료 경로를 재사용한다.
- 제외한 여행·생활 강좌 때문에 공용 도메인·주제 데이터를 삭제하지 않는다.
- 신규 두 교과목의 학습 콘텐츠는 문헌 정리와 후속 검수 전까지 만들지 않는다.
- 수강등록·새 점수·분석·과목별 엔진·실험 A/B 메타데이터를 추가하지 않는다.

## 검증

- `courseModePolicy.test.ts`, `composerPlanning.test.ts`, `learnerCourse.test.ts`: 3파일 24 tests 통과.
- 아래 안전 보완 후 변경한 `learnerCourse.test.ts`만 다시 실행: 7 tests 통과. 최초 sandbox 실행은 esbuild 접근 오류로 테스트 시작 전에 실패했고, 권한 승인 후 통과했다.
- `npm.cmd run typecheck`: 통과.

- 전체 회귀·브라우저·production build는 수행하지 않았다.

## 운영 반영 전 안전 보완

- 기본 구현 커밋은 `dbdfebc`이며 아직 원격에 푸시하지 않았다.
- 운영 DB를 읽기 전용으로 확인했다: 교과목 3개, 주차 45개, 미션 배정 23개, 시나리오 1,403개, 학습 로그 63개. 신규 두 교과목 ID는 기존 데이터와 충돌하지 않는다.
- 교과목·주차·배정 원본과 시나리오·학습 로그의 개수/다이제스트를 로컬 `.tmp/defense-catalog-before-20260827.json`에 보관했다. Git 제외 파일이며 전체 콘텐츠·학습 답안 백업은 아니다.
- migration dry-run은 `20260827093000_seed_defense_course_catalog.sql` 한 건만 표시했다. 실제 적용은 하지 않았다.
- 기존 대표 과목의 9~12주차 배정 7개가 모두 번역 미션이라 새 통역 주차 정책과 충돌했다. 배정·미션·학습 기록은 삭제하지 않고, 학습자 주차 목록에서 수행모드가 맞는 미션만 표시하도록 보완했다. 맞는 미션이 없으면 `준비 중`으로 표시한다.
- migration의 기존 주차 갱신에서 교수자가 설정한 채널·PDR·도메인 등의 맥락값을 초기화하지 않도록 수정했다. 기존 주차 ID와 미션 배정을 보존한다.
- 생성계약·관리자·학습자 정본의 구 9주 수행모드 분모를 실제 학습 12주 정책으로 동기화했다. 생성 프롬프트와 학습 콘텐츠는 변경하지 않았다.

## 반영 보류 사항

- `[독립 검토 필수]`: 저장소 협업 프로토콜에 따라 DB migration을 Claude 읽기 전용 검토에 전달했으나 OAuth 인증 오류(401)로 검토 보고서를 얻지 못했다.
- 운영 DB 적용·푸시·배포는 보류했다. Claude 재인증 또는 이번 건의 독립 검토 생략에 대한 사용자 지시가 필요하다.
- 현재 완료 범위는 세 과목의 설정·편성 구조와 로컬 검증이다. 세 과목의 콘텐츠 완비나 운영 실작동을 검증한 것으로 해석하지 않는다.
