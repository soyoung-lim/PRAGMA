# 학습자·연구 메뉴 축소와 수행 로그 정본화

- 날짜: 2026-08-26
- 목표: 학생 데이터가 쌓이기 전 관리자 메뉴를 과장 없이 정리하되 실제 수업 운영과 논문 자료 준비에
  필요한 경로는 보존한다.

## 결정

- `학습 분석`: 실제 데이터 없는 예시 그래프이므로 메뉴·라우트·화면을 제거했다.
- `학습자 관리`: 가입 승인·동의·가명 ID 운영에 필요해 유지했다.
- `수행 기록 내려받기`: 동의 필터·가명화·기간 선택·JSON/JSONL·내보내기 감사 기록을 갖춘 독립
  연구 기능이므로 유지했다.
- `학습자 수행 기록`: 삭제하지 않고 현행 학습 로그 조회 화면으로 교체했다.
- 검토했던 수행 기록 삭제와 export 보조 버튼화는 최종 채택하지 않았다.

## 구현

- `AdminAnalytics.tsx`와 `/admin/analytics` 진입 경로를 제거했다.
- `AdminDecisionTraces.tsx`가 legacy `decision_traces` 대신 `learner_mission_logs`와 프로필 관계를
  조회하도록 변경했다.
- 목록에서 최근 저장 시각, 학습자, 화행, 미션, 과업, 완료 상태를 표시한다.
- 상세에서 최초 응답, 판단·피드백 기록, 수정 응답, 전이 응답, 목표 특징 관찰과 콘텐츠·정책 버전을
  확인한다.
- 새 DB·집계·차트·분석 점수는 추가하지 않았다.
