# 2026-08-04 · 학습자 장면 감량과 MPJ·피드백 문구 정리

## 확인된 문제

- MPJ3의 이유 찾기 문항이 적색 오류 박스로 시작해, 학습 활동보다 실패 경고로 먼저
  읽혔다.
- MPJ 대화 상단의 `DM 대화 · 표현 비교 중`과 말풍선의 `AI 번역 초안 · 비교 전`이
  학습자가 하는 행동보다 화면 상태를 장황하게 설명했다.
- DCT 장면문에는 기록 목적, 즉각 반응 요구 여부, 상대의 선택권과 완화 필요성 등 평가자가
  알아야 할 기준이 노출됐다. 조사 결과 생성 프롬프트 자체가 이 내용을 `situation_ko`에
  넣도록 강제하고 있어 표시층 축약만으로는 재발을 막을 수 없었다.
- 피드백 하단의 일반 `담화 전체 확인`은 세 기준 카드와 구체 피드백을 반복했다.
- 새 학습자 장면 계약과 달리 미션 AI 품질검사의 `scene_underspecified`는 여전히 말/글,
  즉시 반응, 기록 여부 등 종전 5요소를 요구해, 새로 감량한 장면을 다시 결함으로 판정할
  수 있었다.
- 92px 고정 진행 레일이 긴 문항을 스크롤할 때 본문 상단을 가렸고, `window.scrollBy(180)`
  자동 이동은 실제 고정 높이를 고려하지 않았다.

## 변경

- MPJ3의 적색 박스를 없애고 일반 문항 텍스트
  `이 표현이 상황에 맞지 않는 이유가 무엇인지 고르세요`로 바꿨다.
- MPJ 대화 상단은 `표현 비교`, 말풍선 표기는 `AI 번역 초안` 또는 `AI 통역 초안`으로
  줄였다.
- DCT의 관계 표시는 사용자 결정대로 `상대 · 역할 · 관계`를 한 칩에 유지했다. 별도의
  `상대`·`관계` 태그로 나누지 않는다.
- 일반 `담화 전체 확인`은 학습자 화면에서 제거했다. 다만 실제 초점 이탈 경고인
  `offfocus_warnings`가 존재할 때만 `추가로 확인할 부분`을 조건부로 표시한다.
- 코어 생성 계약을 `core_v8_learner_scene_v1`로 올렸다. 새 `situation_ko`는 상대·과업·
  접촉 이력·실제 부담처럼 학습자가 관찰할 수 있는 사실만 2~3문장으로 제시한다. 기록 목적,
  즉각 반응 여부, 권리·의무·선택권, 필요한 완화·명료성 같은 평가 기준은 내부
  `context_spec`·PDR·target feature에만 둔다.
- `relation_ko`는 상대 역할과 학습자와의 관계를 자연어 한 줄로 함께 쓰며, UI에서도 한 칩을
  유지하도록 생성 계약과 정본에 명시했다.
- 기존 core_v7 저장 행이나 미션은 소급 수정하지 않는다.
- 미션 AI 품질검사의 장면 충분성 기준도 같은 계약으로 정렬했다. 상대·용건·관계/접촉 이력·
  실제 부담 때문에 PDR 판단이 갈리는 경우만 지적하고, 짧은 문장이나 기록 목적·즉시 반응
  설명의 부재만으로 결함을 만들지 않는다.
- 진행 레일은 첫 화면에서 92px 전체형을 유지하고, 160px 이상 스크롤하면 현재 단계만 남긴
  52px 축약형으로 전환한다. 문서 `scroll-padding-top`과 교정안 영역 `scroll-margin-top`을
  실제 고정 높이에 연결하고, 고정값 `scrollBy`는 `scrollIntoView`로 교체했다.
- 첫 CTA는 `4개 장면으로 감 잡기`, 피드백 집계는 `1개 안정 · 2개 점검`처럼 바꿨다.
  개별 문법·화용 카드의 `수정 필요`와 실제 수정 완료 게이트는 그대로 유지했다.
- MPJ 말풍선의 초점 표시는 노란 배경 채움에서 투명 배경의 3px 노란 밑줄로 바꿨다.
  파란 말풍선 안에서 글자와 배경의 대비를 유지하면서 살펴볼 범위만 표시한다.
- 통역 DCT는 밝은 장비 프레임 안에 재생·녹음 조작부만 각각 작은 검은 스튜디오 모듈로
  두었다. 콘솔 전체를 검게 만든 1차 복원안은 덩어리가 크고 전문 장비보다 큰 검은 카드처럼
  보여 축소했다. 최초의 밝은 작업대 톤은 `b07e2a9`(2026-08-02 16:08 KST)에서 들어왔다.
