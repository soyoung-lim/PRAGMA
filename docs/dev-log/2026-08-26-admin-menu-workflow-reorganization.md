# 관리자 메뉴 워크플로 재배치

- 날짜: 2026-08-26
- 목표: 관리자 메뉴를 실제 업무 순서와 연구설계에 맞는 5개 그룹으로 정리하고, 외부 전문가 평가를
  학습 콘텐츠 승인 절차에서 분리한다.

## 결정

- 관리자 메뉴를 `설계 → 제작 → 품질관리 → 수업 운영 → 학습 결과·연구 자료`의 5개 번호 그룹으로
  통일했다.
- `코어`는 내부 스키마 용어로만 남기고 관리자 화면에서는 `시나리오`를 사용한다.
- 품질관리는 `자동 품질 점검 → 교수자 최종 검수·공개`의 두 단계로 경량화했다.
- 전문가 3인은 PRAGMA 설계·사용성에 대한 형성평가 참여자이며 개별 콘텐츠 승인자나 공개 gate가
  아니므로 활성 품질관리 메뉴에서 제외했다. 지도교수는 전문가 참여자에 포함하지 않는다.
- `학습 결과 기반 콘텐츠 개선`은 학습 로그와 품질 점검 결과를 함께 포괄하도록
  `데이터 기반 콘텐츠 개선`으로 확정했다.

## 구현

- 사이드바와 공통 상단 워크플로를 동일한 5단계 정본으로 연결했다.
- `화용적 판정 기준`을 품질관리 부속 단계가 아닌 학습 콘텐츠 설계의 정식 메뉴로 이동했다.
- 품질관리 현황과 교수자 최종 검수 화면을 활성 경로용 경량 화면으로 교체했다. 과거 전문가 관련
  데이터와 이력은 삭제하지 않았다.
- 생성·라이브러리·조립·편성·수업자료·학습자·기록·내보내기 화면 제목을 승인된 용어로 정렬했다.

## 전역 흐름 계층·밀도 보정

- 개별 관리자 화면에 반복되던 가로 흐름은 사이드바와 페이지 내부 절차를 중복하고, 메뉴 위치를 실제
  완료 진척으로 오해하게 만들 수 있어 공통 셸에서 제거했다.
- 운영 대시보드에 남긴 중립형 구조 링크도 각 대분류의 대표 화면을 자의적으로 지정해 실제 메뉴
  구조를 왜곡하므로 최종 제거했다.
- 네이비·옐로우 단계 디자인은 실제 현재 위치를 정확히 나타내는 세로 사이드바에 적용했다. 현재
  대분류만 네이비 면으로 강조하고, 나머지는 네이비 글자·노란 번호·얇은 구분선으로 시각 강도를
  낮췄다. 현재 세부 메뉴는 노란 선택 상태로 구분한다.
- 심사·시연 첫 진입에서 전체 기능 범위가 보이도록 1~5 대분류와 노란 번호를 항상 표시하고 세부
  메뉴도 기본으로 모두 펼친다. 각 대분류는 독립적으로 접고 펼칠 수 있으며, 메뉴
  행과 그룹 간격을 압축해 5번 그룹까지 한 화면에 보일 수 있도록 정보 밀도를 높였다.
- 데이터·라우트·사이드바 정본은 변경하지 않았다.
