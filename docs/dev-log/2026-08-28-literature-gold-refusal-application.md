- `希望下次能参加`는 희망이다. `下次一定参加`로 바꾸면 자연스러운 문장이어도 확약이 추가된다.

- 이 두 예는 **PRAGMA 지도용 작성 예**이며 문헌의 관찰 예·새 채점 정답표와 구별한다.
- 논문에는 ‘문헌 사례·준거 혼동 논의를 기존 자료와 사후 지도에 연결하고, 맥락이 요약 과정에서 누락되지 않도록 출력 경로를 고쳤다’고 기술할 수 있다. **학습효과·척도 타당화·초기 설계 유래·실제 수업 사용 완료**를 주장할 수는 없다.
