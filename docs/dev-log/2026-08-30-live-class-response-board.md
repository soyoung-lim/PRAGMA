# 2026-08-30 실시간 학급 응답 독립 화면

## 목표와 범위

- 수업자료 하단에 접혀 있던 익명 응답 분포를 `/admin/class-responses` 독립 교수자 화면으로 승격했다.
- 이번 작업은 교수자 조회·DEMO·크게 보기에 한정했다. 학습자 공개, 수집/마감/공개 상태, DB migration은 추가하지 않았다.

## 구현

- 사이드바 수업 운영 그룹에 `실시간 학급 응답`을 추가하고 독립 경로를 연결했다.
- 교과목 → 주차 → 미션 선택 후 기존 `learner_mission_logs` 완료 기록을 5초마다 다시 읽어 문항별 익명 분포와 이견 건수만 표시한다.
- 기존 집계 함수를 재사용해 학습자별 최신 완료 기록만 반영한다. 화면과 조회 필드에는 학습자 이름을 사용하지 않으며 `profile_id`와 이견 원문은 렌더링하지 않는다.
- 실제 데이터와 `DEMO · 예시 데이터`를 언제든 전환할 수 있다. DEMO는 코드 fixture이며 DB에 저장하지 않는다.
- 크게 보기에는 사이드바를 숨기고 `가장 많이 선택된 응답이 정답을 의미하지는 않습니다.`라는 해석 경계를 표시한다.
- 수업자료 화면의 중복 분포와 프로젝터 마지막 분포 슬라이드를 제거하고, 선택한 교과목·주차가 유지되는 `응답 보드 열기` 링크로 바꿨다.
