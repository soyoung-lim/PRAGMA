# 관리자 사이드바 글자 크기 미세 조정

## 변경

- 메뉴 항목 글자를 `13px`에서 `13.5px`로 조정했다.
- 그룹 제목 글자를 `12px`에서 `12.5px`로 조정했다.
- 한 화면 수용성을 유지하도록 줄높이, 패딩, 그룹 간격은 변경하지 않았다.

## 검증

- `npm.cmd run typecheck`: 통과
- `git diff --check`: 오류 없음(CRLF 변환 경고만 확인)

## 연구 기록

- 학습 흐름이나 연구 설계에 영향을 주지 않는 경미한 시각 조정이므로 `research-trail`은 갱신하지 않았다.
