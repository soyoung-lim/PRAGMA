# 중→한 통역 장면 역할·노출 가드

- 날짜: 2026-08-05
- 범위: 코어 생성·교정·품질점검과 클라이언트 규칙

## 문제

- 중→한 통역 코어에서 원발화자와 학습자 통역사가 같은 사람으로 합쳐진 두 사례가 C1·C2를 통과했다.
- 학생용 상황문에 `부담을 주지 않으면서도 정중하게`처럼 목표 화용 기준이 노출된 사례도 자동 차단되지 않았다.
- 상황문과 원문의 사건·행위자·대상 불일치는 문자열 규칙만으로 신뢰성 있게 판정할 수 없었다.

## 변경

- 통역 장면을 `A=원발화자`, `학습자=별도 통역사`, `B=목표언어 청자`의 세 참여자로 생성·교정하도록 계약을 강화했다.
- 역할 중첩은 서버 교정과 클라이언트 R16에서 결정론적으로 차단한다.
- 학생용 상황문의 평가 기준 노출을 서버 교정과 새 규칙 R30에서 차단한다.
- core critic을 12축에서 15축으로 늘려 `participant_roles`, `scene_source_alignment`, `learner_scene`을 분리 판정한다. 다국어 의미 대응은 단순 문자열 규칙으로 위장하지 않고 비평 축에 남겼다.
- 후보 릴리스를 `pragma_content_candidate_20260805_01`, 코어 프롬프트를 `core_v9_interpreter_roles_v1`, 품질점검을 `core_quality_v5`로 올렸다.
