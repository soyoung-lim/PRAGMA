# 외부 전문가 검토 부담 제한과 최종 문항 연구자 전수 검토

- 외부 전문가 2인의 범위를 9화행 층화 Gold 18건(화행별 2건), 목표 45분·최대 60분으로 제한했다.
- 정식 AI 학습문항 504개는 전량 품질 점검 자동화 후 연구 책임자가 3~5시간 범위에서 전수 선별·판정하도록 작업대를 추가했다.
- 최종 corpus 문항을 외부 전문가에게 배정하는 경로를 DB에서 차단하고, 504개 원자적 공개에 연구자 승인과 bounded Gold 운영 게이트를 요구했다.
- 18건의 90%·95%는 품질·정확도 추정치가 아니라 운영 게이트라고 화면과 DB 기록에 명시했다.
- 검증: typecheck, 전체 172개 테스트, production build, Supabase dry-run 및 원격 migration 적용 통과. 실제 판정 데이터는 생성하지 않았다.
