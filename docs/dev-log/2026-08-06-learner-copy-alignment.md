# 학습자 화면 문구의 연구 경계 정렬

- 날짜: 2026-08-06
- 범위: 랜딩·강좌·기록 화면의 문구만 변경

## 변경

- 랜딩 설명에 원문 의미 유지와 상황 기반 판단·산출을 명시했다. H1은 변경하지 않았다.
- 강좌 화면의 `9가지 상황`을 `9가지 화행`으로 통일했다.
- 기록 화면의 `같은 화용 초점과 수행 방식`을 `같은 학습 목표와 수행 방식(번역·통역)`으로 바꿨다.
- 다음 미션 행동 문구 10종을 특정 표현을 지시하는 명령형에서 선택 가능한 시도 문구로 낮췄다. 요청 예시 `麻烦您`·`가능하다면…`은 비교 가능한 선택지로 유지했다.
- `/architecture`, 번역 프롬프트, 기존 495, 라우트·정보구조·저장 데이터는 변경하지 않았다.

## 주차 카드 부제 출처 확인

- `부탁을 부드럽게 말하기` 같은 카드 부제는 DB의 주차 `can_do`가 아니다.
- 배정된 reviewed 미션의 `target_feature`를 `src/lib/mission/learnerReport.ts`의 `FRIENDLY_FEATURE_LABEL` 코드 상수로 바꿔 표시한다.
- 카드를 펼쳤을 때 체크표시로 보이는 `can_do` 목록은 DB의 `curriculum_weeks.can_do`에서 온다.
- 따라서 번역·통역을 함께 덮는 `전하기`류 카드 부제가 필요하면, LOCK 후 DB 재생산만으로는 바뀌지 않으며 코드 상수의 별도 개정이 필요하다. 이번 지시 범위에서는 개정하지 않았다.
