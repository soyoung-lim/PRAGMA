# 관리자 사이드바 가독성 조정

## 변경

- `운영 대시보드`를 오른쪽으로 옮기고 옅은 배경·그림자를 적용한 배너형 진입점으로 구분했다. 후속 시각 검토에서 왼쪽 진노랑 강조선은 제거했다.
- 사이드바 시작점을 소폭 올리고 메뉴 항목의 세로 패딩을 `2px`에서 `3px`로 늘렸다.
- 1–4번 그룹 제목을 `12.5px`에서 `13.5px`, 번호를 `10px`에서 `11px`로 키웠다.
- `연구용 예시 검토 — 파일럿`을 데스크톱·모바일 메뉴에서 숨겼다. 화면과 `/admin/research-qa/calibration` 직접 경로는 삭제하지 않았다.

- `npm.cmd run typecheck`: 통과
- `git diff --check`: 오류 없음(CRLF 변환 경고만 확인)

- 핵심 학습 흐름이나 연구 구성개념을 바꾸지 않는 관리자 정보 구조·시각 밀도 조정이므로 `research-trail`은 갱신하지 않았다.
