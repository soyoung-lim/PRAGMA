## 동일 ID 선택 재개 기능

- 관리자 배치 화면의 선택 셀 실행을 ‘현재 ID 재개’와 ‘새 ID 생성’으로 분리했다.
- 브라우저 저장소가 바뀐 뒤에도 과거 실행을 이어갈 수 있도록 기존 코어 run ID 불러오기를
  추가했다. 현재 언어 방향의 `core_{direction}_{timestamp}` 형식만 허용한다.
- 현재 ID 재개는 DB의 기존 item을 먼저 읽어 중복 호출을 건너뛰고, 선택한 셀의 원래 계획
  index를 `generation_item_key`에 유지한다.
- ID 생성·방향 검사를 `coreRunIdentity.ts`로 분리하고 단위 테스트를 추가했다.
