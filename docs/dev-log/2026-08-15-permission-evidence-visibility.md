# 사용자·권한 빈 메뉴 삭제와 권한검사 증거 노출

## 변경

- 사이드바의 `설정 · 사용자·권한(준비 중)` 메뉴와 `/admin/users` 빈 라우트를 삭제했다.
- `/admin/research-qa`의 504개 생성 게이트에서 `세 사용자 역할의 실제 권한 검사` 결과를 펼쳐볼 수 있게 했다.
- 실제 검사 행이 있으면 검사 시각·규약·코드 버전·세 계정 분리·연구자료 생성 건수·전문가 본인 배정 조회·학습자 기록 불변과 검사한 접근 경계를 표시한다.
- 검사 전에는 통과한 것처럼 보이지 않고 실제 세 계정 검사가 아직 실행되지 않았다고 표시한다.

## 검증

- typecheck 통과.
- localhost DOM에서 `사용자·권한` 메뉴 0건, `권한 검사 결과 자세히 보기` 1건을 확인하고 미실행 상태 안내를 펼쳐 확인했다.
