# 라운지·수업 탭 시각 언어 정렬

## 시작 문제

- 라운지는 차가운 보라 배경, 중앙 대형 제목, 굵은 타이포그래피, 파스텔 면 카드와 보라색
  활성 탭을 사용해 수업 탭과 서로 다른 제품처럼 보였다.
- 라운지의 가벼운 성격은 유지하되 학습자 앱의 공통 브랜드·탐색 체계는 같아야 했다.

## 변경

- 라운지 셸을 수업 탭과 같은 따뜻한 공통 배경, 상단 정렬, 콘텐츠 폭과 여백으로 맞췄다.
- 허브 제목을 좌측 노란 세로선과 절제된 크기로 바꾸고, 카드 표면·테두리·그림자를 수업 카드의
  중립적인 언어에 맞췄다.
- 기존 청록·인디고·코럴은 카드 전체 면이 아니라 아이콘, 작은 화살표, 모듈 라벨에만 남겼다.
- 하단 내비게이션의 라운지 전용 보라색 상태를 제거하고 세 탭 모두 같은 노란 활성 표시를 쓴다.
- 라운지 콘텐츠, 3모듈·30개 구조, 선택 동작, 비기록 원칙, 라우트와 데이터 계약은 변경하지 않았다.

  카드 표면과 노란 활성 탭이 공통 언어로 정렬되고 모듈별 색 포인트가 유지되는 것을 확인했다.
