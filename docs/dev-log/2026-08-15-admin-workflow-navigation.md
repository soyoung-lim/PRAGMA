# 관리자 사이드바를 실제 작업 순서로 재편

## 변경

- 그룹 번호를 없애고 `재료와 규칙 → 문항 생성 → 품질 검증과 공개 → 수업 편성 → 학습자와 연구자료` 순서로 사이드바를 재구성했다.
- 품질 검증 절차만 1~4단계로 유지했다. 학기 종료 후 수행하는 `수행기록 내려받기`는 `학습자와 연구자료`로 이동했다.
- 개별 생성과 배치 생성을 사이드바의 `문항 생성` 한 항목으로 묶고, 두 생성 화면 상단에 동일한 전환 탭을 추가했다.
- 실제 기능이 없는 `/admin/review` 안내 화면을 제거했다. 저장된 주소는 `학습 미션 조립`으로 이동하며, 이 화면의 `reviewed` 처리는 `내부 확인 완료`로 표현한다.
- 정식 학습자 공개 결정은 품질 검증 4단계에서만 수행한다. 관련 DB 공개 게이트는 변경하지 않았다.
- 시나리오 아카이브를 `흐름 밖 참조` 영역으로 분리했다.
- 품질 전체 현황 안의 별도 1~5 번호 목록을 번호 없는 확인 항목으로 바꿔, 1~4단계와 번호가 경쟁하지 않게 했다.

## 검증

- `npm.cmd test`: 173개 통과, 4개 건너뜀.
- `npm.cmd run typecheck`: 통과.
- `npm.cmd run build`: 통과.
- 변경 파일 대상 ESLint: 통과. `npm.cmd run lint` 전체 실행은 저장소에 기존부터 남아 있는 `no-explicit-any`, sparse array 등 23개 오류로 실패했다.
- localhost DOM에서 새 사이드바 순서, 품질 검증 4단계, 개별·배치 생성 탭, 수행기록 내려받기의 연구자료 그룹 배치를 확인했다.
