# 2026-08-06 · 콜드 오픈 카드뉴스 로컬 프로토타입

## 배경·판단

- 사용자가 신간 소개 카드뉴스의 짧은 서사 리듬을 PRAGMA에 적용하는 아이디어를 제안했다.
- 미션 내부 장면마다 3장을 추가하면 4개 MPJ 앞에 최대 12번의 넘김이 생기므로 적용 위치를
  미션 시작 설명이 아니라 기존 DCT 콜드 오픈으로 한정했다.
- 기존 단일 암전 패널은 정보를 압축하지만 다음 내용을 궁금하게 만드는 박자가 약하다는 사용자
  판단에 따라 로컬 시각 프로토타입을 만들었다. 최종 시각 채택 여부는 사용자 확인 전이다.

## 구현

- 기존 `production_task.situation_ko`를 새 생성 없이 `오늘의 장면 → 장면 속 단서 → 당신의
  선택` 3장으로 편집한다.
- 1장은 첫 문장, 2장은 `그런데, 이런 사정이 있습니다`와 나머지 상황 사실, 3장은 목표언어
  질문과 `먼저 네 장면을 살펴보고, 이 장면으로 돌아옵니다`라는 예고를 보여 준다.
- 번역에서 기존 `preceding_turn`이 있으면 3장에 `도착한 메시지` 말풍선으로 보여 주고,
  MPJ 4개 뒤 DCT 위에 `처음 그 장면으로 돌아왔습니다`를 표시해 예고를 회수한다.
- 통역 `AudioFrame`은 현재 `preceding_turn`을 사용하지 않으므로, 통역 카드에는 이 말풍선을
  추가하지 않았다. 번역·통역 수행 화면과 콜드 오픈이 서로 다른 사실을 보지 않게 한 경계다.
- `classifyColdOpen`은 이미 화행 코드와 무관하게 비어 있지 않은 `preceding_turn`을 보존하고
  관련 회귀도 있으므로 수정하지 않았다. 문제는 분류가 아니라 카드의 미렌더링이었다.
- P·D·R, 목표 대역, 정답·평가 기준은 새로 노출하지 않는다. 도착한 메시지는 번역 DCT가
  원래부터 보여 주던 상황 사실을 앞에서 예고한 것이다.
- 자동 재생 없이 점·이전·다음으로 이동하고, 1·2장 모두 `바로 시작`으로 건너뛸 수 있다.
- 카드 구간에서도 스텝퍼 라벨을 회색으로 표시하되 높이는 그대로 유지해 헤더 진동 경계를
  바꾸지 않았다.
- 번역은 화행별 질문, 통역은 `어떻게 통역하면 좋을까?`로 종결 문구를 분리했다.
- 작은 화면에서는 이전 행동을 화살표로 축약하고 보조 숫자를 숨겨 2장의 세 행동이 줄바꿈되지
  않게 했다.
- 카드 전환은 짧은 CSS 모션을 쓰되 `prefers-reduced-motion`에서는 제거한다.
