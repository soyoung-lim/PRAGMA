# 2026-08-22 · 수업 데이터 백업·복원 배포

## 배경

지도교수의 사용자 데이터 관리 요구에 따라, 교강사가 자신이 구성한 한 교과목의 15주
수업 데이터를 파일로 소유하고 다른 PRAGMA 설치본에서도 복원할 수 있는 경로를 추가했다.
학습자 수행자료 내보내기와 수업 구성 백업은 목적과 개인정보 경계가 달라 별도 기능으로
유지한다.

## 구현 범위

- 백업 단위는 교과목(`curriculum_outline`) 1건, 주차 편성, 주차별 미션 배정과 그 배정이
  참조하는 시나리오다.
- 인증정보, 검수자 식별자와 학습자 수행 기록은 포함하지 않는다.
- 백업 파일은 포맷 버전과 생성 시각, 교과목 식별정보, 포함 행을 가진 JSON이다.
- 복원 전에는 형식·참조 무결성·비밀정보 의심 값을 검사한다.
- 복원은 선택한 교과목 범위 안에서만 주차와 배정을 백업 시점의 exact snapshot으로 맞춘다.
  공유 시나리오 본문과 다른 교과목, 학습자 기록은 삭제하지 않는다.
- 복원 직전의 현재 상태를 별도 안전 백업으로 자동 내려받는다.
- 파일명은 `PRAGMA_학기_핵심과목명_YYYYMMDD_HHMMSS.json` 형식으로, 같은 날 반복
  백업이 서로 덮어쓰지 않게 했다.
