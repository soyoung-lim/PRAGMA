# 승인 미션 기반 교수자 수업자료

- 날짜: 2026-08-25
- 목표: 별도 교안 시스템이나 새 DB 없이 승인된 MPJ5+DCT1 미션을 수업에서 바로 쓰는
  교수자 운영 자료로 연결한다.

## 구현

- 준비 중이던 `/admin/package`를 승인 미션 선택·검색·인쇄가 가능한 실제 화면으로 교체했다.
- 미션 JSON을 다음 여섯 단계로 결정적으로 투영한다.
  1. 상황과 화행
  2. 대표 오개념과 첫 판단
  3. P·D·R 최소대조
  4. 중국어 화용 현미경
  5. MPJ 후보·DCT 허용안 토론
  6. 다른 맥락으로 재맥락화
- `/admin/assembly`의 검토 완료 미션에서 해당 수업자료로 바로 이동한다.
- MPJ1·2가 실제로 P·D·R 한 축만 바꾼 경우에만 최소대조라고 표시한다. 복합 차이이면
  특정 축의 효과를 단정하지 않는 경고를 보여 준다.
- 실제 학습자 사례 자동 선별은 하지 않고 교수자가 수행 기록에서 익명 사례를 고르게 했다.

## 최소 검증

- `instructorGuide.test.ts`, `adminNavigation.test.ts`: 5개 통과
- `npm run typecheck`: 통과
- `git diff --check`: 내용 오류 없음(CRLF 안내만 있음)
- 전체 테스트·별도 로컬 build·새 DB migration·AI 호출은 수행하지 않았다.

## 운영 검증

- 첫 운영 배포에서 기존 공개 `mission_v5` 일부가 저장상 MPJ4이지만 학습자 실행기에서는 결합된
  판단·교정을 나눠 MPJ5로 보여 준다는 호환 차이를 확인했다. 교수자 자료도 같은 방식으로
  `첫인상→맥락 판단→교정→이유→여러 초안` 5단계로 투영하도록 보정했다.
- Railway `3fd8d05d-1dd5-4377-a55f-ff4e3dd7da2c`는 SUCCESS이며 image digest는
  `sha256:53d38933d5e018320056ecd1ee60ffc3bf0680fc9279a53f4026fa543c04f85f`다.
- 운영 공개 미션 `86d738b0-1891-4bfe-9b12-f8643ebbb45f`에서 MPJ1–5 수업자료,
  여섯 단계 제목, 인쇄·PDF 버튼과 재맥락화 문구를 확인했다.
