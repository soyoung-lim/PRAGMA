## 13주 제안 — 아직 채택·구현하지 않음

사용자는 7·14주를 WRAP-UP 및 메타화용 토론으로 이해하고, 13주의 불명확한 역할을 지적했다.
앞선 `새 맥락 적용`은 모든 화행 주차의 서로 다른 두 상황 수행과 구분이 약하다.

- 제안 명칭: **선택 화행 보완 실습**.
- 교강사가 앞선 학급 수행의 선택·수정 근거를 검토해 보완할 기학습 화행 두 개를 선정한다.
  자동 진단·개인별 추천이나 학생 자유 선택 기능이 있다는 뜻은 아니다.
- 새 상황의 독립적인 완전 미션 두 개를 수행한다. 앞서 제안한 병행안에서는 번역 1개와 통역
  1개로 두며, 14주는 이 수행까지 포함해 학기 전체의 판단·수정 근거를 토론한다.
- 신규 미션 수는 과목당 20개라는 앞선 제안과 같다. 새 화행·새 평가기·추가 시험은 필요하지 않다.
- 현행 `고부담 맥락 집중 실전` 계약과 실제 13주 설정을 이번에 변경하지 않았다.

관련 검토 정본: `docs/dev-log/2026-09-05-three-course-strategy-review.md`.
명칭 변경은 연구 구성개념·학습 흐름을 바꾸지 않고 13주안은 미채택이므로 research-trail은
갱신하지 않았다. 주차 설계 채택 시 해당 결정과 정본·구현을 함께 갱신한다.

## 후속 질문 — 13주를 하나의 화행으로 좁힐지

사용자가 교강사가 보완할 화행을 선정하는 방향을 받아들이고, 화행 수를 두 개에서 한 개로
줄이는 대안을 질문했다. 최신 권고는 **하나의 화행 + 서로 다른 상황의 번역·통역 미션 각 1개**다.
앞선 두 화행안은 넓은 보완 범위가 장점이지만 화행별 수행 모드가 하나씩이다. 한 화행안은
기존 화행 주차와 같은 단위를 유지하면서 해당 화행을 두 방식으로 집중 보완할 수 있다.
과목당 신규 미션 계획량 20개는 그대로다. 14주는 이 결과까지 포함한 종합 메타화용 토론이다.

교강사가 학급 공통 화행을 선정하는 기본안을 뜻하며, 자동 진단·개인별 편성 기능을 추가하거나
이미 구현했다고 설명하지 않는다. 화행 수 최종 채택과 주차 규칙 변경은 아직 수행하지 않았다.
