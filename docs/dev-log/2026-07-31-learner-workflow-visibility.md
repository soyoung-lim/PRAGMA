## 배경

학습자 화면이 일반 LMS의 과제함처럼 읽힌다는 문제 제기. 원인 진단 결과 콘텐츠가 아니라
화면마다 단계 이름과 순서가 달라 하나의 여정으로 읽히지 않는 것이었다.

## 한 것

### 1. 조사(josa) 하드코딩 수정 — `36dd457`

`db42e78`에서 `josa()`가 사라지고 조사가 다시 하드코딩돼 있었다. band·feature 라벨은
받침 유무가 섞여 있어 비요청 초점에서 `지나치게 장황'로`처럼 깨진다. `josa()`를 복원해
6곳에 적용했다(ㄹ 받침 예외, 후행 따옴표 제거 후 판정, 한글 아니면 기본형).
`learnerCopy`는 중국어 폴백이라 조사 판정이 원리상 불가해 `… 표현을 써봤어요`로 문구를
바꿨다. 회귀 = josa 단위 4건 + 비요청 초점(거절/`over_elaborate`) 리포트 1건.

### 2. 워크플로우 표시 정본 신설 — `d5d3618`

`src/lib/curriculum/learnerWorkflow.ts`에 단계 이름·순서를 모았다. 5단계(장면 이해하기 →
표현 비교하기 → 직접 번역/통역하기 → 피드백 살피기 → 다시 다듬기), 학습자 동사가 앞이고
MPJ·DCT는 보조 라벨. `MPJ_ITEM_COUNT = 4`를 테스트로 고정했다(v1·v2 legacy만 5문항).

미션에 `intro` 국면을 추가해 시작 전 여정 미리보기를 두고, 3단계 네이비 필을 진행
레일(완료=노란 원+체크, 현재=노란 링 3.5px, 예정=회색 테두리, 연결선은 지나온 구간만
노랑)로 교체했다. 죽은 정의 `STAGE_OF`·`stageSteps`·`STEP_INDEX`는 제거했다.

대시보드 「학습자 수행 기록」이 프로토타입 시절 `decision_traces`를 세고 있어 실제 미션
기록이 쌓여도 0이었다. `learner_mission_logs`로 바꾸고, `head:true`가 권한 거부를 삼키고
0을 돌려주므로 본문 응답을 받도록 했다.

### 3. 홈·주차 과잉 프레이밍 되돌림 — `04347a0`

홈 5단계 목록은 미션이 이미 보여 주는 것을 반복해 제거했다. 주차 화면의
`① 원리 익히기 → ② 미션`은 이름을 잘못 붙인 것이라 되돌렸다. Roever 교수 단계의
Hook·귀납·명시적 원리 설명은 주차 학습 노트가 아니라 도입 아크(L1~L4)이고, 노트는
예습·복습면이다.

### 4. 도입 아크 배선 — `50edc8c`, 게이트 차단은 후속 커밋

아크가 개발 전용 경로에만 있어 배포된 앱에는 산출 전 교수 단계가 보이지 않았다.
production 라우트 `/learner/course/week/:weekNo/intro`를 열고, 주차 화면에 진입점을 두고,
아크 종료 시 해당 주차의 실제 미션으로 합류하게 했다(기존에는 샘플 미션으로 갔다).

이어진 콘텐츠 검수에서 결함 5건(Hook 인과 불성립, 대조 사례 변인 혼입, 대역–길이 완전
공변, 과잉 예시 비현실성, 미션 band와 용어 불일치)을 확인해 `ARC_READY_FEATURES`를 빈
목록으로 두어 학습자 노출을 차단했다. 배선은 유지하므로 콘텐츠가 준비되면 목록에 특징
코드를 넣으면 열린다. → `DEC-20260731-06`, `EVD-20260731-07`

필요 아크 수는 9개다. 2~11주에 화행이 하나씩 배치되고 화행당 목표 특징이 하나이므로
해당 주차 전부가 최초 등장이다.
