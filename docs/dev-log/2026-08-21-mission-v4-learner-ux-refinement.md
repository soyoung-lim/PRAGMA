## 10단계 피드백·요약 구조 반영

- 기존 8단계에 `피드백·다듬기 1`과 `피드백·다듬기 2`를 각각의 DCT 직후 배치해 총 10단계로 구성했다. 최종 요약은 번호 없는 완료 화면으로 분리했다.
- 피드백 화면은 짧은 AI 분석 중 상태 뒤에 학생의 실제 답안, `의미 충실성`·`문법 정확성`·`화용 적절성` 3기준, 정확한 문제 구간, 구체적인 이유와 수정안을 보여 준다.
- 기준별 상태는 `매우 좋음`·`보완 권장`·`수정 필요`로 통일하고, 문제가 있는 기준만 노랑 또는 절제된 코랄로 강조한다.
- 학생용 설명은 `뜻이 빠짐없이 전달됐나요?`·`중국어 표현이 정확하고 자연스러운가요?`·`이 관계와 상황에 잘 맞나요?`로 풀어 썼다.
- `head act`와 `supportive moves`는 `핵심 요청`과 `덧붙임` 메타데이터로 유지하되 학생 피드백 화면에서는 노출하지 않는다. 덧붙임은 원문에 명시된 인사·이유·사과 등만 기록해 기능주의적 조정이 임의의 의미 추가로 이어지지 않게 했다.
- 주차별 `초점` 표시는 제거했다. 최종 요약은 일반 원리, 두 상황의 차이, 다른 표현, 학습자의 두 최종 번역만 남긴다.

## 학생 답안 중심 피드백·완료 요약 개편

- 피드백 화면에서 긴 원문·상황 메타데이터·대안 목록·이론 설명을 제거하고, 실제 학생 답안 → 표시된 문제 구간 → 이유 → 가능한 수정안 → 다음 번역에서 기억할 한 가지 순서로 재구성했다.
- 답안 내부에 표시할 수 없는 의미 누락은 억지로 밑줄치지 않고 `빠진 내용`으로 구분한다.
- 최종 완료 화면에서 서로 다른 두 DCT를 좌우 비교하던 구조를 폐기하고, 각 답안을 독립된 세로 기록으로 제시한다.
- 완료 화면은 최초 답안, 실제 수정 구간과 이유, 최종 번역을 보존하고, 두 답안에서 확인된 세 기준의 결과만 `이번 활동에서 보인 패턴`으로 집계한다.
- 안내 문구로 시작하는 값은 유효 답안으로 인정하지 않아 제출·요약에 포함되지 않도록 했다.
