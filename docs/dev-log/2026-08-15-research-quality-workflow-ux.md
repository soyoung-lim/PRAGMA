# 문항 품질·연구자료 화면의 용어와 업무 흐름 개편

- 날짜: 2026-08-15
- 범위: 관리자 연구 메뉴, 연구 책임자·외부 전문가 작업 화면, 학습 콘텐츠 개선과 연구용 데이터 내려받기

## 시작 문제

- `기준문항`, `연구자`, `전문가`, `생성 문항`, `검증`, `검수`, `공개`, `연구 참여 데이터`가 대상·행위자·결과를 바로 설명하지 못했다.
- 기술 구현 단위가 메뉴 구조에 그대로 드러나 실제 연구 운영 순서와 정보 위계가 불명확했다.
- 학습자·전문가 신호를 이용하는 개선 기능이 연구 검증 메뉴에 섞여 있었다.

## 수행한 변경

- 연구 메뉴를 다섯 단계의 실제 업무 흐름으로 재구성했다: 품질검사 기준답안 작성 → 기준답안 외부 전문가 확인 → AI 학습문항 외부 전문가 확인 → 통과 문항을 PRAGMA 학습자 화면에 공개 → 학습 수행기록 연구용 내려받기.
- `연구 책임자`, `외부 전문가`, `품질검사 기준답안`, `AI 학습문항`의 뜻을 화면 안에서 설명하는 공통 안내를 추가했다.
- 같은 외부 전문가 2인이 두 단계에 각각 독립적으로 참여할 수 있으며 4인이 필수는 아니라는 운영 원칙을 명시했다. 두 단계의 배정·회차·판정 기록은 분리한다.
- 외부 전문가 화면을 `상황·의미 확인 → 중국어 표현 판정 → 종합 판정` 순서로 재구성하고, 내부 규칙 ID와 위험 ID는 쉬운 한국어 설명 뒤의 고급 정보로 내렸다.
- 관리자 비교 화면을 `전문가 등록 → 2인 독립 배정 → 판정 비교 → 최종 결정` 순서로 정리했다.
- `오류·개선 제안함`을 `학습 콘텐츠 개선`으로 바꾸고 `3 · 학습자·학습 분석`으로 이동했다.
- `공개`는 외부 웹 게시가 아니라 검토를 통과한 문항을 PRAGMA 학습자·수업 화면에서 사용할 수 있게 하는 일이라고 명시했다.
- `연구 참여 데이터 추출`을 `학습 수행기록 연구용 내려받기`로 바꾸고 동의·가명화 조건을 함께 설명했다.
